# 도로를 먼저 보고 이름과 참고 그림을 함께 생성한 시제품

2026-10-14. 사용자는 주변 도로 모양에서 닮은 대상과 기준 그림을 함께 생성하는 방식을 선택했고, 정규화된 선 그림을 외부 서버 AI에 보내는 앱 연결도 허용했다. 아래 시제품은 외부 API 실행 전의 별도 에이전트 생성·평가 기록이다.

원래 3지역에서 이름이나 고정 도형을 사용하지 않고 자연 도로 고리를 수집해 6개를 선택했다. 모두 실제 간선으로 닫혀 있고 원래 영역 안에 있으며 3–8km 조건과 반복 제약을 통과했다. 실제 길이는 3,029.725–7,900.530m, 노드 수는 73/241/245/80/82/181이다. 입력 PNG에는 전체 실제 노드를 보존했다. 모델 입력에는 위치·주소를 제거한 단위 좌표와 익명 ID만 포함했다. 좌표를 제거해도 독특한 도로 모양 자체가 위치의 단서가 될 수 있다.

생성 에이전트는 gpt-6.1-sol로 4개 임시 해석과 2개 보류를 반환했다. 참고 그림은 검증 가능한 M/L/Q/C/Z 명령만 사용하며 실제로 보이는 부분의 경로 범위, 상상으로 추가한 부분, 부족한 특징, 생성 출처를 따로 기록했다. 6개 응답의 구조 검증은 통과했지만 의미 정확성을 인증하지 않는다.

별도 에이전트는 먼저 이름을 보지 않고 원래 6개 선 그림만 평가해 판정을 잠갔다. recognizable 0, unclear 3, none 3이었다. 이후 생성 이름과 참고 그림을 보고 아래처럼 평가했다. 생성자와 판정자는 다른 에이전트지만 같은 모델 계열이다.

| 후보 | 생성 해석 | 이름 납득도 | 참고 윤곽 충실도 | 안내 유용성 |
|---|---|---:|---:|---:|
| road-01 | 옆얼굴 | 65 | 92 | 70 |
| road-02 | 서 있는 공룡 | 68 | 84 | 76 |
| road-03 | 꼬리를 든 고양이 | 56 | 88 | 64 |
| road-04 | 말풍선 | 60 | 88 | 72 |
| road-05 | 보류 | — | — | — |
| road-06 | 보류 | — | — | — |

4개 이름의 납득도 평균은 62.25, 윤곽 충실도 평균은 88이었다. 윤곽 충실도는 도로 선을 잘 따라 설명했는지를 뜻하며 대상 이름의 자연스러운 인식을 입증하지 않는다. 제안 이름과 원래 자유 명명이 정확히 같았던 것은 옆얼굴 1개이며 그 판정도 unclear 35였다. 숫자는 주관적 AI 평가이고 사람의 인식률·성공 확률·원래 고정 도형 유사도가 아니다. 보류를 정상 결과로 유지한다.

별도 미리보기에는 이름 없는 최초 판정, 판정 잠금 후 AI 해석 공개, 실제 경로/참고 윤곽/상상선 구분, 참고선과 상상선 전환, JSON 내보내기를 구현했다. 실제 브라우저의 로컬 파일 접근이 보안 정책으로 거절돼 브라우저 QA는 완료하지 못했다. 우회하지 않았고 저장된 HTML을 오프라인 JSDOM으로 실행해 6개 카드의 판정 잠금·전환·정규화된 내보내기 동작을 검증했다. 사람 판정이나 실제 다운로드는 만들지 않았다.

생성 자료와 평가 전후 입력 해시는 보존됐다. 원래 기하학 점수·실제 경로·고정 12조건을 덮지 않았다. 최신 원래 12조건 자동 평균은 여전히 77.416667이며 목표 80은 달성하지 못했다. GPT-5.4 Mini 외부 API의 품질·비용은 이 시제품으로 검증되지 않았다.
