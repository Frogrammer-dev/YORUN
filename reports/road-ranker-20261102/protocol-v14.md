# v14 복수 특징 경계 보존: 실제 도로 생성 A/B

이 문서는 신규 도로 생성 전에 고정한다. 가설은 복수 식별 특징의 폭·깊이·상대 배치와 독립 도로 경계를 보존하면 같은 배치의 일반 완성보다 이름 없는 인식이 늘어난다는 것이다. 템플릿 구조 가설이며 해부학 인식 정답이 아니다.

## 범위·처리

boundary-bank-v14.json의25종×3개 개발 지역75조건·4398배치를 양쪽에 그대로 사용한다. 이전1003개 도로에서 만든 배치 top3의 이동0/−5%/+5%,각도0/−15/+15,최초60고유 배치 목록이며 새 도로 결과를 보고 바꾸지 않는다. 원래12조건·점수식·holdout-v2·앱 기본은 보존한다.

A는 원래 외곽의 순서대로 모든 anchor를 일반 도로 탐색한다. B는 정의된 두 특징 경계를 먼저 독립된 노드/무방향 간선으로 예약하고 나머지 몸통을 완성한다. 특징 내부에 다른 body anchor가 접속하지 못하고 원래 특징 entry/exit만 연결점으로 사용한다. 몸통끼리 재사용은 허용하며 최종 반복률은 기존 기준을 따른다. 표본 좌표는 전부 실제 그래프 노드다. 직선 가짜 연결·스무딩·꾸밈선은 없다.

원래 외곽의 마지막 닫힘 중복점을 제거하고 각 vertex를 .12*placement.scale 이내 가장 가까운 실제 노드에 붙인다. 두 방식은 동일한 pins와 고정 배치를 사용한다. 공유 전처리는 그래프 구성·전75조건 anchor 준비 포함 총60초 안전 상한이다. 넘으면 남은 조건을 전처리 실패로 분모에 남긴다.

특징 정의는18종이며 fish,whale,house,apple,mug,pants,hammer는 두 독립 특징을 정의하지 못했다. 이7종은 B가 A의 최종 pool을 그대로 사용하는 명시적 fallback이다. 새 구조 개선으로 세지 않으며 B의 독립 생성 지원은18/25로 보고한다.25종 범위에서 기존 가능한 추천을 불필요하게 제거하지 않는다. 지원18종에서 B 생성 실패 시 A fallback을 추가하지 않는다.

각 method/request는 배치 최대60회, 탐색1회당12000확장, 누적200만확장 또는15초 중 먼저 도달하면 중단한다. 완성·실제도로감사·점수 계산 시간도 요청15초에 포함하고 단계별 수치를 기록한다. A/B 예산 상한은 같으나 실제 소비가 같다고 주장하지 않는다. B fallback은 검색하지 않아 공동 A 비용과 재사용을 표시한다. 전체 테스트 상한40분, 진행 중 매 요청 기록, 중도 실패·부분 결과·보류 모두75분모 유지.

## 유효성·선택

snapshot 파일SHA256·그래프 simple/excludeSteps와 영역을 고정한다. 연속 실제 간선·폐곡선·영역, native/projected 길이 각각3–8km,무방향 간선 길이 반복 각각<=.2를 검사한다. 특징 사슬이 최종 순환경로에 실제 순서로 남는지도 확인한다.

지원종의 고정된 template 배치 좌표계에서 특징 폭·깊이·상대 거리 비율[.5,1.5],각도차<=30°를 적용한다. 후보에 맞춰 frame을 재정렬하지 않는다. A는 충족 여부를 기록하며 실패해도 유효 경로면 pool에 남긴다. B는 두 특징 조건과 노드/간선 독립성 모두 충족해야 pool에 남긴다.

두 방식 모두 원래 evaluatePath.similarity 내림차순·동률ID사전순으로 동일 undirected geometry를 중복 제거해 최대8개를 남기고 첫1개를 추천한다. CLIP/학습 head gate나 AI 판정으로 pool/순위를 바꾸지 않는다. 표시 방향은 canonical −generatorPlacement.rotDeg로 동일 고정한다. 원래 유사도는 보조 수치이지 사물 인식 성공이 아니다.

## 사전 판정

기술 지지: B의 유효 최종 요청 감소가 A 대비<=3/75이고, 동물33요청 중 두 특징 충족 추천이 최소6조건 증가. 미지원종은 특징 개선0이며 fallback을 개선으로 부풀리지 않는다.

의미 지지: 사전 primary 평가자의 B target-clear가 A보다>=5/75,동물에서>=3/33 증가하고 최소2종에 걸쳐야 한다. 기존 엄격 다양성 gate(동물3종·사물3종이 각각2지역 이상 명확),3AI 다수결·평가자별 원본,기존 첫후보8/75도 별도 보존한다. 보조 다수결만 오른 것을 primary 성공으로 바꾸지 않는다. 부족한 추천은 보류 실패다.

이름/점수/방법/참고를 숨긴 중립 이미지 자유 명명으로 판정한다. 기존 동일 본문 픽셀은 원래 판정에 연결하고 상충하면 새 검토한다. 이미 개발에 참여한 같은 계열AI이고 개발3지역임을 명시하며 사람 평가나 독립holdout이라고 하지 않는다. 실제 사람 검토 화면·원본GPX도 제공한다. 특징 지표만 좋아지고 인식이 그대로면 해당 구조 가설은 의미 성공 기준 미달로 기록한다.
