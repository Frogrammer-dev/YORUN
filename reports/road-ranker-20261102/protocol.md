# 실제 도로 후보 선택 모델: 사전 실험 계획

작성: 2026-11-02. 사용자 요청으로 AI 전문가 협업을 재개했다.

목표는 이름이나 참고 그림 없이 실제 도로 경로가 사물로 읽히는 결과다. 모델이 출력하는 것은 검증된 원본 도로 후보 ID와 선택 점수다. 곡선 보정 좌표를 주행 경로로 쓰지 않는다.

## 가설과 비교

H1: 도로형 계단/격자 변형을 학습하고 일반 도형에 대한 거절을 학습하면, 원본 스케치만 학습한 같은 구조보다 변형 스케치 분류와 거절이 개선된다. 기존 Quick Draw 590개 manifest의 train/val/test 분할과 클래스별 분모를 그대로 유지한다. 합성 일반 도형은 합성 음성 예제이며 실제 도로의 사물 없음 정답으로 간주하지 않는다. 기존 test는 과거 실험에서 본 자료이므로 신규 독립 데이터라고 부르지 않는다.

같은 구조, optimizer, epoch/계산 예산, seed17/29로 clean 대 road augmentation을 비교한다. 모델/거절 임계값은 validation에서 고정하고 test 결과로 바꾸지 않는다. 보조 통과 기준은 두 seed 모두 변형 test 정확도 +5%p 이상 또는 합성 음성 오수락 상대 20% 이상 감소, 원본 정확도 하락 3%p 이하이다. 이 기준을 통과해도 실제 도로 인식 성공은 아니다.

H2: 같은 실제 도로 후보 풀에서 학습 모델의 선택이 반환순 선택보다 명확하게 읽히는 사물을 더 제공한다. 대전/대구/송파의 기존 개발 도로 스냅샷을 사용한다. holdout-v2와 원래 고정12조건은 건드리지 않는다. 자연 고리 seed83721/StepBudget2000, 영역별 최대120개를 모델 점수 없이 도로 간선 중복을 줄여 표집한다. 정밀 거리3~8km/반복20%/영역/폐곡선/실제간선을 모두 검사한다. 기존18개도 동일 풀에 포함해 기준선을 보존한다.

실도로 검토는 지역별 반환순2개와 모델 선택2개를 동일 렌더러로 익명화한다. 동일 후보는 한 번만 평가하고 양 방법에 귀속한다. 최종 그림에는 이름/점수/목표그림/지도배경을 노출하지 않는다. 자유 명명, 명확/약한 연상/없음을 먼저 고정한다. AI 검토는 AI 대리지표로 표시한다. AI 대리지표의 가시적 개선 기준은 6개 요청 중 명확 인식 +2개 이상, 도로 유효성100%, 양 방법 분모6 보존이다. 선택기가 모두 거절한 슬롯도 실패에 포함한다. 사람 3명 이상 자유명명 전까지 사람 인식률은 미측정이다.

## 기록과 적용

모델 체크포인트/자료/후보 풀 해시, 전체 실패/거절/소요시간, 지역별 결과를 기록한다. 실패하면 가설을 수정하고 다음 회차의 기준을 실행 전에 추가한다. 단순히 합성 test 점수가 좋아졌다는 이유로 앱 기본 모델을 교체하지 않는다. 검토용 페이지와 실제 도로 GPX를 제공한다.
