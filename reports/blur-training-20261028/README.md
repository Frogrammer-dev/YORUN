# 원본 학습과 흐림 증강 학습: 실제 학습 대조 결과

## 실행 범위

Google Quick Draw 기존 선별590개, apple/fish/bird3종의 단일 폐곡선. 기존 원본 단위 분할 train413/val88/test89 유지. CC BY4.0, 출처 https://github.com/googlecreativelab/quickdraw-dataset . ImageNet은 사용하지 않았다. 현재 사진24장은 선 복원 정답으로 검수되지 않았고 클래스별 학습량도 부족하다. 이번 자료에는 사물 식별 내부선이 없으므로 열린 뚜껑 등의 복원은 검증하지 못한다.

CNN이64px 선 그림을 입력받아64점 윤곽과3클래스 로짓을 출력한다. 정답 라벨을 입력하지 않는다. 원본 전용 A와 sigma0/1/2 균등 혼합 B를 초기값17/29로 각각30epoch 학습, 총4체크포인트 저장. 초기값·배치순서·학습량·구조 동일. 검증 원본+sigma1 복원MSE로 checkpoint 선택. 테스트는 선택 후 시행. 약32.4초 CPU 실행(환경별 상이).

## 결과

아래는 두 초기값의 평균 정규화 Chamfer 거리(작을수록 좋음). 신뢰구간이나 대규모 반복실험이 아니며 두 seed 평균만으로 통계적 유의성을 주장하지 않는다.

| 테스트 입력 | 원본 학습 | 흐림 학습 | 해석 |
|---|---:|---:|---|
| 원본 | 0.048397 | 0.049192 | 약1.6% 악화 |
| sigma1 | 0.065841 | 0.048965 | 약25.6% 감소 |
| sigma2 | 0.088166 | 0.049182 | 약44.2% 감소 |
| 격자 변형 | 0.054391 | 0.055006 | 약1.1% 악화 |

격자 변형 오차 개선률은 seed17에서+0.32%, seed29에서-2.69%. 사전 기준인 두 seed 모두10% 개선을 만족하지 못했다. 원본 분류정확도는 두 seed 모두96.63%→95.51%(89개 중86→85). 이는 제한된3종 그림 분류이며 사람 인식률·전체 사물 인식률·실제 도로 정확도가 아니다. 클래스별 값과 검증곡선은 summary.json에 있다.

**판정: 흐림 증강은 흐린 이미지 복원에 유효한 예비 결과. 도로풍 변형 일반화 가설은 미지지.** 격자 반올림은 실제 도로의 연결·왕복·부분 누락·복잡한 변형을 대변하지 못한다. 새로운 도로 경로를 만들거나 실제 도로에 적용한 성과는 없다.

## 후속 방향

흐림만으로 작은 특징을 무시하도록 학습시키는 방법을 단독 해결책으로 채택하지 않는다. 다음 가설은 실제 병목과 가까운 계단/돌출/부분 누락 증강을 두 방식에 동일하게 제공하고, 흐림 추가 효과만 분리하는 것이다. 현재 테스트 결과를 본 뒤 새 설정을 시험하면 개발 반복으로 표시해야 하며 최종 평가에는 별도 고정 미사용 자료가 필요하다. 내부선 복원에는 검수된 내부선 정답 자료를 먼저 확보해야 한다.
