## 실험 방법과 한계

- 전국 OSM 저장 데이터 기준: 2026-10-09T20:21:04Z. 광안리·서면·강남 각각 같은 영역, 같은 도로 그래프를 사용했습니다.

- LLM 역할은 도로 이미지를 보고 위치·크기·회전 방향 5개를 제안하는 것입니다. 실제 연결은 공유된 OSM 노드만 사용하는 기존 알고리즘이며 가짜 직선 연결은 생성하지 않습니다.
- 1차는 도로 지도만 보고 제안했습니다. 2차는 1차 점수·경로·기존 결과 그림도 확인하고 수정했습니다. 동일 사례를 보며 수정했으므로 일반화 성능 또는 독립 검증 성능이 아닙니다.
- 기존은 사례당 64~68회, LLM은 한 라운드당 최대 55회 실제 경로 연결을 평가합니다. LLM 시드는 고정된 주변 이동·크기·회전 10종으로 보정하며 기존 비용식으로 선택합니다. 2차까지의 누적 계산량은 더 큽니다.
- 고정 연결 실험은 같은 2차 제안에서 flex 변형 단계를 제거한 진단용 비교입니다. 평균은 60.7점으로 낮아졌습니다.
- 기하학 유사도는 기존 `evaluatePath`를 그대로 사용했습니다. 점수식·임계값은 변경하지 않았습니다. 80점이 사람의 인식률 80%라는 뜻은 아닙니다. 별도 사람 평가는 하지 않았습니다.
