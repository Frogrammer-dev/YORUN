# 요런 모바일 러닝

설치형 앱에서 요런의 HTTPS 배포 주소를 열어 기존 코스 선택·러닝·작품방을 사용한다. 웹과 기록기에는 같은 버전의 변경을 배포해야 한다. 달리기 시작·일시정지·종료는 러닝 화면에서 조작한다. OS가 잠금 중 수신한 좌표는 기기 SQLite에 보관하고 러닝 화면으로 복귀하면 같은 달리기에 시간순으로 반영한다. GPX 내보내기는 러닝 결과 화면에서 선택할 수 있다.

## 개발과 출시 후보

이 폴더에서 npm ci를 실행하고 EXPO_PUBLIC_YORUN_ORIGIN을 실제 HTTPS 배포 주소로 설정한다. Android SDK가 있는 개발 컴퓨터에서는 npm run android, Xcode와 개발 서명이 설정된 Mac에서는 npm run ios -- --device를 사용한다. Expo Go에서는 이 백그라운드 작업을 검증할 수 없다.

EAS의 preview 및 production 환경에도 같은 주소를 설정한다. eas build --profile preview --platform android로 내부 APK를 만든다. iOS 내부 배포에는 등록한 기기와 서명이 필요하다. 출시 빌드는 eas build --profile production --platform android 또는 ios로 생성한다. 서명·스토어 제출은 각각의 소유자 계정에서 진행한다.

## 실기기 합격 기준

- 시작 직후 정확한 위치·백그라운드 위치를 허용한다. 대략적인 위치, 위치 거절, 알림 거절도 별도로 확인한다.
- 코스를 선택한 뒤 잠금 상태로 5분 이상 진행해 회전 안내와 GPS 수신을 확인한다. 화면 복귀 후 지점 수·수신 시각·저장 시각과 경로를 비교한다. 60초를 넘게 끊긴 구간은 지도와 GPX에 연결선이 없어야 한다.
- 일시정지·재개·종료와 결과 화면 재진입을 확인한다. 포인트가 한 번만 지급되고 작품방으로 이동할 수 있어야 한다.
- 기록 관리에서 삭제한 뒤 재실행해 기기 원본과 이전 버전의 임시 GPX가 남지 않는지 확인한다. 웹에서 별도 저장한 파일과 완성한 작품은 별도로 관리한다.
- Android 릴리스 APK의 최종 권한, 포그라운드 서비스 알림과 iOS 위치 표시를 확인한다. 스토어 제출 전 백그라운드 위치 사용 사유, 실제 화면 시연, 위치 데이터 처리 안내를 준비한다.
- OS가 강제 종료한 동안의 위치는 복원할 수 없다. 잠금 중 절전 정책, 무수신 상태, 통신 단절 후 재실행과 복귀도 실기기로 검사한다.
