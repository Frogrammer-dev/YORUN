# 핵심 구간 선확보: 기술 타당성 v1

새 방식: 기준 그림의 짧은 식별 구간에 대응하는 실제 도로 두 구간을 먼저 만들고, 이 구간을 변경하지 않은 채 나머지 외곽을 연결한다. 사진 누끼와 모델 학습은 사용하지 않는다.

기존 개발6조건/배치/그림을 유지한다. 그림은 사람 인식 검증 완료 자료가 아니므로 참고 그림 블라인드 판정도 별도 준비한다. bird 부리(6,7,8), apple 줄기(0,1,2), turtle 머리(1,2,3), car 지붕(2,3,4)를 처음 대상으로 고정한다. 이 한 부분이 사물 전체를 정의한다는 가정은 하지 않는다.

각 꼭짓점 주변3개 실제 노드(최대 반경 scale*0.12)의27조합. 두 구간을 guide-weight1.5 A* 최대12000확장으로 잇는다. 서로 즉시 되돌아가거나 중복 노드를 만드는 구간은 거절한다. 나머지 꼭짓점은 최근접 노드로 고정하여 가이드 A*로 연결한다. 핵심 구간 간선을 결과에 그대로 보존하고 길이3–8km/닫힘/영역/실제간선/반복20%를 검사한다.

선택: 유효 후보 중 핵심 두 선분과 실제 핵심 경로의 평균 거리 + 꼭짓점 이동거리 평균(배치scale정규화) 최소. 생성-선택용 지표이며 최종 독립 평가가 아니다.

저장된 기존 baseline은 참고 표시만 한다. 추가27후보 탐색과 계산 예산이 달라 성능 우월성을 주장하지 않는다. 전조건 실패도 포함. 성공은 '유효 경로에 강제 확보 구간이 보존됐는가'의 기술적 의미뿐이다. 실제 사람이 이름 없이 사물로 인식하는지 미평가로 남긴다. 고정12조건/앱 기본 변경 없음. 미검증 상태에서 GPU 모델 설치/외부 비용 없음.
