# 동물 포함 학습 선택기: 진행 기록

최종 상태: 특징 추출·학습·추론·3AI 비교 완료. head4/75·prototype1/75·기존8/75로 도로 개선 실패다. 아래는 실행 중의 역사적 기록이며 현재 상태는 [최종 보고서](v12-results.md)와 v12-progress.json을 따른다. 목표는 미완료이며 다음 설계 검토는 v13-generation-expert-plan.md다.

v12 프로토콜을 먼저 고정하고 기존19범주1368개를 정확히 보존한 상태로 동물11종·사과·왕관을 추가했다. 공식 자료에 로켓이 없어 수집 조건 실패를 명시했으며, 학습 지원은24종이다. 로켓3조건은 전체25종×3지역75분모에 남긴다. 총2304개, train1646/val316/test342이며 road 판정은 학습에 사용하지 않는다.

현재 새 손그림과 기존1003개 실제 도로의 동일 렌더러·4회전 특징 추출을 실행 중이다. 이어서 균형ridge/prototype 학습과 요청별 선택을 비교한다. 학습 개선·도로 인식 개선·사람 성공은 아직 주장하지 않는다. 성공 기준은 protocol-v12.md를 따르며 결과를 보고 낮추지 않는다.

입력 감사는 v12-data-audit.json, 실행 추적은 v12-progress.json, 공식 자료 수집 기록은 sketch-data-v12.json에 있다. 특징 추출의 세션 정보는 추적용이며 다음 실행 시 실제 프로세스 상태를 확인해야 한다.

새 자료 범위 설정과 프로토콜·보고서 분리 회귀 검사를 포함해 sketch-features Python5검사, 표시 회전이 GPX 좌표를 바꾸지 않는 diversity-review 검사를 통과했다. 최종 모델과 도로 비교는 아직 실행 전이다.
