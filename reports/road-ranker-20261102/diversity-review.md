# 다양한 사물·동물25종 검토

2026-11-02 사용자 추가 요청에 따른 실제 도로 검토다. 동물11종·사물14종을 천안불당·전주효자·울산삼산에서 각각 검색했다. **도로 생성과 이름 없는 인식 판정을 구분하며, 사람 인식률은 미측정이다.**

비교 화면에는 이름과 원본 외곽이 있으므로 이를 본 뒤의 납득도를 익명 인식률로 세면 안 된다. 독립 평가자는 이름 없는 화면을 먼저 사용한다. 각 유효 경로의 원본 GPX도 제공한다.

사람 평가 화면은 평가자 코드 변경 시 답변 초기화와 저장 차단 환경을 확인한 별도 출력이다. 기존 AI 평가 이미지·대응표는 보존했고 새 fingerprint를 이전 AI 응답과 섞지 않는다. 집계 도구는 동결 카탈로그의 바이트 해시도 확인한다. 실제 사람 응답은 아직 없다.

## 범위와 실제 결과

- 25종×3지역=75요청 모두에서 실제 유효 도로 후보를 얻었다. 신규 후보는 동물220개·사물233개로 총453개이며, 기존550개를 보존했다.
- 모든 포함 경로는 실제 연속 간선·폐곡선·영역·native/projected 거리3~8km·반복20% 이하를 검사했다. 길이 유효하다는 것만으로 사물 인식 성공이라고 하지 않는다.
- 각 요청에서 의미 모델 점수 없이 생성기 순위 첫 유효 후보를 고정했다. 이75표본의 세 AI 자유 명명에서 다수결 명확은 동물2/33, 사물6/42, 합계8/75였다. 75개 밖의 다른 후보에 대한 가능성 상한은 아니다.
- 평가자별 명확 판정은0/75,10/75,11/75로 차이가 크다. 사람 평가가 아니며, 동일 계열AI의 상관된 오류 가능성도 남는다.
- 바지는3지역 모두, 물고기·오리·티셔츠·의자·망치는 각각1지역에서 대상 이름과 명확 판정이 다수결로 일치했다. 최소3개 동물종·3개 사물종이 각각2지역 이상에서 지지된다는 보조 기준은 미달이다.

## 무엇을 보완해야 하나

- 동물: 물고기는 몸통·꼬리 연결, 오리는 부리·목·몸통이 식별 단서다. 현재는 각각 한 지역의 표본만 명확했다. 고양이·토끼의 귀, 기린의 목, 코끼리의 코, 네발동물의 다리 간격을 보존하는지 다음 대조 실험에서 확인해야 한다.
- 사물: 바지의 두 다리 사이 빈 공간은 세 지역에서 읽혔다. 망치·티셔츠·의자는 일부만 지지됐다. 손잡이·병목·바퀴·줄기 등의 작은 특징이 없는 단순 외곽은 다른 물건이나 다각형으로 읽힐 수 있다.
- 위 특징·위험 설명은 템플릿 구조에 근거한 가설이다. 실제 특징 보존 정도를 별도 수치로 측정했다고 주장하지 않는다. 코드상 기하학 유사도나 모델 점수가 높다는 이유로 이름을 강제로 붙이지 않는다.
- 학습 head v10은 사물11종과 일반 경쟁8종으로 학습했으며 동물 학습 범주는0종이다. 따라서 동물 미지원은 도로 생성 실패와 별개다. 동물까지 평가하려면 그 범주를 포함한 학습 및 다른 지역·사람 검증이 필요하다.
- 거북이는 기존 이름 사전에서 turtle 대신 sea_turtle만 있다. 비교 카탈로그의 관련 명칭 표시는 일반 거북이 학습·성능을 증명하지 않는다. 동결 생성 기록의 엄격한 alias 지원 여부는 미지원으로 남겼고 자동 대체하지 않았다.

## 실행·판정의 한계와 보존

- 동일 attempts60·fullRotation·최대pool8,75요청을 고정했다. 공유 안전 상한19분30초와 테스트20분 제한을 적용했으나 소진·부분 실패·오류는 모두0이었다. 실행 약378.2초. 이전 무제한 실험과 같은 예산의 모델 우위로 주장하지 않는다.
- 모델 점수로 좋은 예시를 미리 뽑지 않았다. 대상별 첫 생성 후보를 사용했으며 이름·참고 그림·점수·방법을 숨긴5개 이미지 페이지로 판정했다. 25종 전체·3지역 분모와 불명확 판정을 보존했다.
- 선별 예시 그림은 판정 후 고른6종이며 전체75개 중8개 명확이라는 결과를 대신하지 않는다. 실제 사람 인식률이나 보편적인 동물 인식 성공으로 확대하지 않는다.
- 원본 고정12조건·점수식·holdout-v2·앱 기본·원본v9후보550개는 보존했다. 이3지역은 이미 본 개발 자료이므로 새 독립holdout이라고 부르지 않는다.
- 원본 판정은 ai-review-v11-rater*.json, 집계는 diversity-v11-ai-results.json, 도로 감사는 diversity-v11.json 및 diversity-v11.md, 실행 조건은 protocol-v11*.md에 있다.

## 학습 모델v10 결과도 별도로 보존

공식 Quick Draw19범주1368개를 그룹 분할(train960/val200/test208)해 결정적 균형ridge head를 학습했다. 손그림 test의 클래스 평균 정확도는 head93.19%, prototype84.93%로8.26%p 차이였고, 일반 경쟁 범주 오수락은4.76% 대9.52%였다. 이는 손그림 보조 지표이며 도로 인식이나 사람 정확도가 아니다.

별도의 도로 top2/지역 비교에서는 head의 개발용3AI 명확 다수결이2/6, prototype0/6, 기존v9 1/6이었다. 기존 선택보다2개 이상 증가해야 한다는v10 기준에는 미달했다. 또한 해당 평가 이미지 경로에 head/prototype라는 방법 힌트가 있어 완전한 방법 맹검이 아니었다. 유리한 방법 성과로 확정하지 않으며 개발 참고로만 남긴다. 이75개 다양성 평가의 중립적인 파일 경로에는 방법 힌트가 없다.
