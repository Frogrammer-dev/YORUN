# 요런 중간발표 — Figma Slides 디자인 브리프

2026-10-22. 사용자 선택: Canva 대신 Figma. 발표는 10월 26일, 10분. 본문·수치 근거는 [중간발표 평가](contest-midterm-review-20261022.md)를 따른다. Figma 계정 연결 전 준비 문서이며 실제 Figma 파일은 아직 생성하지 않았다.

## 디자인 방향

“동네가 캔버스, 러너가 붓.” 지도 위 경로가 마지막에 작품으로 이어지는 시각적 흐름을 만든다. 스포츠 서비스의 선명함과 작은 전시회의 여백을 조합한다. 본문은 밝은 배경, 표지·시연·마지막 장은 어두운 배경으로 구분한다.

- 화면: 16:9, 1920×1080 기준. 바깥 여백 112px, 요소 간격은 24/48px 중심.
- 색: 기존 앱 토큰의 파랑 #0A72D6, 잉크 #111318, 밝은 배경 #F5F6F8, 흰색 #FFFFFF. 어두운 장의 경로는 #38BDF8.
- 글꼴: Pretendard 사용 가능 여부를 확인하고 없으면 Noto Sans KR. 제목 64–80px, 본문 32–38px, 근거·출처 24px 이상.
- 한 장당 주장 하나, 주요 시각 자료 하나. 화면 캡처는 글자가 읽힐 정도로 자르고 관련 기능을 크게 보여 준다.
- 그래프와 텍스트는 편집 가능한 요소로 작성한다. 실제 경로는 원본 비율과 선을 보존한다.
- 상태는 색뿐 아니라 ‘구현’, ‘시험’, ‘미검증’ 글자로 구분한다. 예시 그림과 모의 GPS는 화면에 표시한다.

## 장별 레이아웃과 문구

| 장 | 제목 | 레이아웃·시각 자료 |
|---|---|---|
| 1 | 달린 길이, 나의 작품이 된다 | 어두운 배경. 왼쪽 제목과 요런 이름, 오른쪽 경로 작품 하나. 하단 ‘아이디어 경진대회 중간발표 · 2026.10.26’. 팀·발표자 이름은 확인 후 입력 |
| 2 | 그림 러닝, 코스 준비부터 어렵다면? | 밝은 배경. 코스 설계 → 길 연결 확인 → 기록 보관을 간단한 선 도식으로. ‘초기 문제 가설’ 표기. 확인되지 않은 인터뷰·통계 금지 |
| 3 | 찾고, 달리고, 작품으로 남긴다 | 코스 선택·러닝·작품방의 실제 화면 3장과 짧은 캡션. 화살표는 동일한 파란 경로선으로 연결 |
| 4 | 현재 시제품의 한 번의 사용 | 어두운 배경, 영상 영역을 크게 배치. 60–90초 시연. 영상 미확보 시 실제 화면 3단계로 대체하고 ‘시연 준비 중’ 표시 |
| 5 | 실제 길 위에 그림을 만드는 과정 | 도로 연결 / 그림 품질 / 모바일 기록의 세 행. 각 행은 문제 → 대응 구조. 실제 연결과 파일 전달 방식이 드러나는 작은 도식 |
| 6 | 고정 조건에서 경로 품질을 개선했다 | 0–100 동일 축 막대 65.75, 77.42. 80 목표선. ‘오프라인 12조건 · 기하학 유사도’ 표시. 하단 3지역×4그림·3–8km·추가 계산 포함·앱 기본 성능 아님 |
| 7 | 이제 실제 사용을 검증한다 | 왼쪽 Android 30분 기록 시험, 오른쪽 사용자 5명 내외 관찰 계획. 결과가 확보되기 전에는 계획형 문구 유지 |
| 8 | 구현한 것과 남은 것 | 웹 핵심 흐름=구현, Android APK=빌드, iOS·실기기=검증 필요, 웹↔앱=파일 전달의 4행 상태표. 임의 완성률 금지 |
| 9 | 최종발표까지 확인할 세 가지 | 기록 안정성 → 사용 흐름 통합 → 사용자 재시험. 각 단계 아래 완료 기준 한 줄. 미정 날짜·담당자 생성 금지 |
| 10 | 나만의 코스를 달리고, 나만의 작품을 남기다 | 어두운 배경, 큰 작품 한 장과 한 문장. ‘다음 검증: 사용자가 스스로 코스를 고르고 작품까지 완성하는가?’ |

## 필요한 자료와 검수

1. 최신 앱의 코스·러닝·작품방 화면 캡처. 데모 상태면 캡션으로 구분.
2. 같은 조건의 실제 생성 경로 성공·실패 사례. 꾸밈선을 실제 기록에 섞지 않기.
3. 시연 영상 또는 대체 정지 화면. 사용자·실기기 결과가 없으면 계획으로 유지.
4. 연결 후 Figma Slides 생성·편집 기능을 확인하고 실제 파일에서 시안을 작성.
5. 내보내기 형식 확인 후 제출 파일을 별도로 검수. PPTX가 필요하면 글꼴·배치·영상 유지 여부를 PowerPoint에서 확인.

미완료 자료 때문에 거짓 화면이나 성과를 만들지 않는다. 첫 디자인 검토는 표지·사용 흐름·품질 결과 3장의 시각적 일관성부터 확인한다.
