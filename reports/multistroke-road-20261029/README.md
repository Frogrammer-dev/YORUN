# 복원 다중 획과 실제 도로 연결

seed17 sparse의 클래스별 첫 테스트 그림을 고정해 대전/대구/송파 실제 로컬 OSM 그래프에 연결했다. 3그림×3지역×27배치=243배치. 원본 획 안32점의 최근접 도로노드를 guideA*로 연결, 획 사이와 최종 출발점 복귀도 실제도로로 연결하여 모두 거리/반복/그림에 포함했다. 단순한 직선 이동/텔레포트 없음. 그림 순서 고정, 크기1개, 회전3개 및 위치9개이므로 가능성 상한 실험이 아니다.

## 결과

유효3/9조건. 모두 사과: 대전7.39km/반복10.8%, 대구6.86km/9.1%, 송파7.88km/4.4%. 3개 모두 실제간선/영역/폐곡선/native+projected3–8km/반복20%검사 통과. 총 유효 후보5개.

물고기/새6조건은 모두 실패. 각 조건의 기하학상 가장가까운 연결후보는 물고기8.43–10.13km, 새14.58–16.15km. 획 사이 이동만 물고기2.22–2.31km, 새4.47–4.83km. 이 후보는 실패 진단용으로만 공개하며 실제 추천으로 표시하지 않는다. 대구/송파 새는 한 획이 동일도로노드로 축소됐다. 전체후보 실패사유는 summary.json에 복수집계(합계가27을 초과할 수 있음).

대전3종 비교 이미지를 시각 확인: 복원그림의 큰 배치는 일부 남지만 실제 도로 계단/돌출 및 획사이 연결선이 형태를 바꾼다. 명명된 AI 진단이며 사람 인식 성공을 측정한 것이 아니다. 유효사과3개도 사람이 알아보는지 미검증이다.

## 적용 범위·다음 병목

복원 출력→실제 도로 변환 실험 연결을 구현했다. 앱 기본 자동추천은 변경하지 않았다. 복원 성능 향상이 도로 실현성으로 그대로 이어지지 않음을 확인했다. 입력은 선택한 그림이며 도로에서 사물을 자동 발견한 것이 아니다. 현재 문제는 그림복원뿐 아니라 크기·획방문순서·연결선 길이이다. 후속은 동일 그림의 획방향/방문순서와 크기를 최적화하여 연결비용을 줄이는 대조가 필요하다. 내부선을 삭제하거나 거리제약을 완화해 성공으로 바꾸지 않는다.

원래 고정12조건 점수식/평가 및 holdout-v2는 변경하지 않았다. 선택에 사용한 대칭 선분거리에는 노드밀도편향이 있으며 사물 인식 점수가 아니다. 점획의 방문만으로 눈 모양을 표현했다고 볼 수 없다. 지도간선은 현실의 최신 보행 가능성을 보증하지 않는다.
