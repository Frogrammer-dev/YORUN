## 실제 수행
기존 사진/저장 U2NetP 마스크를 고정하고 세 가지 표현을 생성했다: 외곽만, 외곽+내부 경계 전체, 외곽+다중 크기에서 유지되는 내부 경계. sigma1/2/3 Canny50/120, 2px 근방 일치, 침식 마스크 내부, 짧은 성분 제거. 새 모델 학습이나 누끼 개선은 이번에 수행하지 않았다.

24장 중20장에서 선별 내부 선 생성. 내부 픽셀68547→8841(약87.1% 감소). 이는 선량 감소일 뿐 인식률 향상도 정확한 구조 선택률도 아니다. 4장 무선 결과도24장 분모에 포함한다. 경량 그림처리 결과이지 사물 부품을 이해하는 모델은 아니다.

## 시각 검토 (비블라인드 개발 관찰)
24장을 사진과 함께 확인했다. 독립 사람 평가는 아니다.
- 새: 날개/몸통 경계가 외곽에 없는 정보를 제공한다.
- 호랑이: 얼굴·몸통 및 일부 줄무늬가 남는다. 줄무늬는 식별에 도움될 수도 있지만 실제 도로로 모두 구현하기 어렵다.
- 만화책: 인쇄 그림도 유지된다. 지속성 필터가 의미적 구조를 구분하지 못한다.
- 넥타이: 무늬가 내부 구조처럼 남는다.
- 테이프플레이어·흔들의자: 강한 필터가 버튼/프레임 등 필요한 정보도 지운다.
- 캔따개 사진: 캔 윗부분의 내부 경계가 일부 나타나지만 손·포장·캔 혼합과 잘못된 외곽은 그대로다. 반쯤 열린 뚜껑 정답 주석이 없고 해당 예시 해결을 입증하지 않았다.

외곽만의 표현 한계를 보완할 가능성은 확인했지만, 중요 내부 선 자동 선택 가설은 아직 미입증이다. 누끼/대상 선택 오류를 내부 선으로 덮어 해결했다고 판단하지 않는다.

## 연결 표현
내부 선 골격에서 끝점·분기점 사이의 획과 독립 고리를 추적해 이미지 좌표 그래프로 저장한다. 외곽은 별도 outerStrokes(각각 닫힌 윤곽)로 보관한다. 내부 획은 열린/닫힌 상태를 끝점 비교로 구분할 수 있다. 단일점은 isolatedPixels에 기록한다. 획 사이를 임의의 직선으로 잇지 않는다. 마스크 침식으로 외곽 근처 내부 선이 끊길 수 있으며 외곽과 내부 그래프 접합 복원은 미구현이다.

분기/고리 단위검사 통과. 모든 이미지 골격에서 실제 인접 간선 수와 추적한 간선 수 동일성 검사 통과. 이는 이미지 연결 검사이며 실제 도로 경로 검사가 아니다. 전체 이미지를 한붓으로 주행하는 경로는 생성하지 않았다.
