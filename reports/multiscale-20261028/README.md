# 흐림 기반 다중 선명도 진단

기존 개발6조건×3방식의 저장된 결과를 고정했다. 유효17개, 생성 실패1개를 유지했다. 새 경로 생성이나 학습, 앱 기본 변경 없음. 사전 규칙: `reports/multiscale-protocol-20261028.md`.

256px 캔버스에 선3px, 긴 변216px로 렌더링하고 Gaussian sigma0/2/5/10을 적용했다. 원본 도로 좌표를 변형하거나 그림 선을 추가하지 않았다. 기준 그림은 각 결과의 배치된 outline을 사용했다. 도로와 기준을 각각 중심/크기 정규화했으므로 위치·크기 일치 검증은 아니다. 회전은 유지했다.

## 관찰

17출력에서 기준 선 그림과 잉크 코사인 유사도 평균은 0.177→0.385→0.689→0.889. 이것은 인식 정확도 상승이 아니다. 흐림이 두 선의 어긋남을 덮어 점수가 높아질 수 있다. 강한 흐림으로만 순위를 매기면6조건 중2조건의 선택 방식이 바뀌지만, 더 알아보기 쉬운지는 확인되지 않았다.

사전 고정한 min(sigma0,2,5) 순위는6조건 모두 원본 선택과 동일하다. 이번 데이터에서는 원본 점수가 최솟값이 되어 다중 선명도의 추가 정보가 선택에 반영되지 않는 한계가 있다. 이 결과로 흐림 접근 전체를 기각하지 않지만 이 보수 점수식을 추천기 개선으로 채택할 근거는 없다. 전체 후보 풀 대신 이미 선택된 최대3출력만 비교했다는 제한도 있다.

18행의 원본/흐림 몽타주를 시각 확인했다. 잔가지와 계단은 약해지지만 강한 흐림에서 긴 타원·둥근 덩어리처럼 단순해지고 식별 특징도 지워지는 경우가 보인다. 개발자가 대상명을 아는 상태에서 한 AI 진단이며 독립 사람 평가가 아니다. 현재 실험에는 서로 다른 대상·무작위 윤곽의 음성 대조가 없으므로 의미 구분 능력도 검증되지 않았다.

## 다음 검증

흐림을 보조 표현으로 유지하되, 학습/선택 지표를 바꾸기 전에 원본과 약한 흐림에서 자유 명명을 별도로 수집한다. 사진처럼 채운 면이 아니라 실제 달리는 선만으로 평가한다. 후속 지표 실험에서는 다른 대상의 참고 그림 및 비사물 도로 고리를 음성 대조로 포함하여 흐림이 모든 모양의 점수를 무차별 상승시키는지 검사해야 한다. 음성 대조 없이0.889를88.9% 인식률이라고 표현해서는 안 된다.
