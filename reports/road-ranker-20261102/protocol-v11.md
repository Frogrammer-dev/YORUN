# 11회차: 다양한 사물·동물의 범위 검토

2026-11-02 사용자 추가 지시: 여러 다양한 사물과 동물에 대해 검토한다. 현재 학습 head는 사물11종과 일반 경쟁8종이고 동물은0종이다. 현재 head로 동물 성능을 주장하거나 망치 예시를 전체 범주 성공으로 확대하지 않는다. v10 학습·선택 결과는 보존하며 별도 집계를 마친다.

## 고정 검토 범위

- 동물11종: cat,fish,dog,rabbit,bird,whale,turtle,elephant,giraffe,butterfly,duck.
- 기존 사물8종: house,tree,car,rocket,apple,crown,airplane,mug.
- 추가 사물6종: tshirt,pants,hammer,bottle,key,chair.

총25종을 모두 검토한다. 원본 SHAPES와 별도 OBJECT_TEMPLATES를 그대로 사용한다. 새로운 정의나 동의어를 결과에 맞춰 추가하지 않는다. 각 종의 식별 특징(귀/꼬리/목/부리/날개/다리/손잡이 등), 외곽선만으로 잃는 특징, 격자 도로에서 실현하기 어려운 구조를 기록한다. 종별로 사람 인식 가능성에 관한 가설과 실제 검증 결과를 구분한다.

## 실제 도로 검토

v9의 동결된 천안불당·전주효자·울산삼산 스냅샷을 사용한다. 각25종×3지역=75요청에 동일 globalSearch attempts60/fullRotation/rankBySimilarity,각pool8이하,preserveHypotheses:true를 적용한다. 계산량이 기존보다 증가한 범위 검토이며 동일 예산의 성능 개선이라고 표현하지 않는다.

연속 실제간선·폐곡선·정밀native/projected3~8km·반복20%·영역을 모두 검사한다. 실패·보류·예산·시간을 모든75요청 분모에 포함한다. 원본v9후보550개를 보존한다. 새 후보는 지역/종/경로/배치를 구분하고 같은 실제 도로의 다른 사물 가설도 보존한다. 원래12조건·점수식·holdout-v2·앱 기본은 수정하지 않는다.

모델 점수 없이 각 요청에서 생성기 순위가 가장 높은 유효 후보 하나를 고정해 검토 표본을 만든다. 이름/참고 그림/점수/종류/지역/방법을 숨긴 자유 명명 AI 진단을 별도로 받는다. 후보가 없는 요청도 분모에서 빼지 않는다. 모델 최고점으로 미리 선별한 표본과 섞지 않는다. 이것은 전체 후보의 가능성 상한이나 실제 사람 평가가 아니다.

## 판정과 산출물

종별 실제 도로 생성 성공/실패, 특징 손상, 현재 학습 head 지원 여부, CLIP 이름 사전 지원 여부를 분리한다. 특히 학습 모델 미지원은 도로 생성 불가능이나 사람 인식 실패로 간주하지 않는다. CLIP 이름이 없는 rocket은 대체 이름을 강제로 정답 처리하지 않는다.

다양성 범위 검토의 완료 조건:25종×3지역의 누락 없는 기록, 모두의 도로 유효성 검사, 동물/사물별 결과 표, 실제 도로와 원본 외곽 비교 화면, 이름을 가린 표본 진단과 미측정 사항의 표시다. 최소3개 다른 동물 종과3개 다른 사물 종이 각각2지역 이상에서 AI 자유 명명 clear로 지지되는지 보조 지표로 기록하되 미달도 그대로 남긴다. 이 기준을 만족해도 실제 사람 인식 검증은 별도다.

이후 학습 범위를 확장하려면 동물 데이터와 open-set 경쟁 범주를 사전에 고정한 새 계획으로 진행한다. 기존 사물만으로 학습한 head의 숫자를 동물 전체 인식률로 보고하지 않는다.

### 이름 사전 확인

사전의 거북이 이름은 `turtle`이 아니라 `sea_turtle`(바다거북)이다. 이름이 지원된다는 표에는 이 제한을 명시한다. 일반 거북이 전 범주에 대한 성능을 증명한 것으로 확대하지 않는다. 자유 명명 판정은 사전 이름으로 대체하거나 수정하지 않는다.

### 자유 이름 일치 사전

동물 검토 그림의 이름을 받기 전에 `src/lib/route/diversityCatalog.ts`의 `freeNameAliases`를 고정했다. 정규화는 Unicode NFKC·소문자·공백과 구두점 제거만 사용한다. 예를 들어 개/강아지, 컵/머그컵을 포함하되 결과를 보고 동의어를 늘리지 않는다. clear-any와 원래 대상 이름 일치를 따로 기록한다. 새를 오리라고 하거나 고래를 물고기라고 명명한 경우 같은 대상으로 강제 변환하지 않는다. 실제 자유 이름과 알려진 다른 해석도 원문으로 남긴다.
