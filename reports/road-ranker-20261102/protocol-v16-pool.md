# v16 고정 후보 풀: top1 선택 누락 진단

v11 첫후보의3AI 명확8/75,v12학습4/75,v13방향7/75,v14일반3/75·특징2/75,v15사람3탐색명확0을 보존한다. 이 실패가 후보 생성 부족인지 선택 누락인지 아직 분리하지 못했다. 이번에는 신규 geometry/모델 학습 없이 동결1003후보를 표집한다.

## 표집

입력 diversity-v11.json의25종×3지역75요청을 그대로 사용한다. 요청별 baseline reviewSlot의 geometryKey를 제외한다. 나머지는 같은 area/proposalShape에서 무방향 간선집합 geometryKey로 중복 제거하고 sourceID 사전순 최소행을 대표로 고정한다. SHA256("v16-fixed-pool|"+area+"|"+proposalShape+"|"+geometryKey),sourceID 순으로 정렬해 첫2geometry를 각각 대안1·2로 고정한다. CLIP/head/AI 이름·점수·generatorSimilarity는 표집에 쓰지 않는다.

계획 대안150슬롯 중 실제로 다른 geometry가 부족한 슬롯은 NA로 남긴다. 사전 원시 metadata 집계는 대안140장,완전대안없음2요청이었다. 누락에 가짜 그림/none응답을 넣지 않는다.25종·75요청 지원 분모와 실제 관측 이미지 분모를 모두 보고한다. 원래1003행·좌표·배치·점수는 바꾸지 않고 원본 canonical 방향(−generatorPlacement.rotDeg)으로 표시한다. 같은 geometry의 다른 방향을 best-of-views로 선택하지 않는다.

## 판정과 의미

각 대안은 중립 파일명·무작위토큰으로 이름·원본그림·방법·점수를 숨겨3AI 자유 명명한다. primary01a19aed-73d8-7662-81ef-5d6ec2287589와보조01a19b0b-12bd-7592-9a5f-809818cebc3a/01a19b0b-13a1-7340-89c7-095b3dc85ed2를 그대로 유지한다. 원래 동의어를 변경하지 않는다. 기존 동일보디픽셀은 원판정에 연결하고 상충하면 신규검토한다. 개발에 참여한 동일계열AI·이미본3지역이며 독립 사람/holdout평가가 아니다.

요청별 baseline/대안1/대안2의 target-clear 유무를 별도로 기록한다. baseline 실패 중 대안에서 하나 이상 target-clear가 나온 요청 수를 **표집에서 확인한 선택 누락의 하한**으로 본다. 여러 대안 중 사후 clear를 고른 집계는 달성가능성 진단이지 자동 top1 모델의 성능이 아니다. 전체 풀의 상한/전수oracle라고 하지 않는다. 다른 사물로 명확한 경우도 자유이름과 함께 보존하며 target정답으로 바꾸지 않는다.

진단 지지 제안선은 baseline 실패요청 중 >=5/75 추가 target-clear,그중 동물>=3/33·최소2종이다. 엄격 primary와3AI다수결을 각각 기록하고 보조만의 성과를 primary성공으로 승격하지 않는다. 기존 동물3종·사물3종 각각2지역 gate·기존8/75·75전체 분모도 보존한다. 대안2개에서 개선이 없어도 전체geometry풀에 좋은 후보가 없다는 결론은 금지한다.

실행 전 전문가 검토 반영: 위 진단 지지선의 주판정은 기존 primary이며 같은 조건의 다수결은 보조다. 후보 이미지별3AI 판정을 먼저 확정하고 그 뒤 요청별 union을 계산한다. 다른 이미지의 표를 모아 한 이미지에 합의가 생긴 것처럼 계산하지 않는다. 각 대안 단독의 추가 요청 수·세 평가자별 union·union 다양성 gate도 별도 기록한다. geometryKey는 area/roadHash/정렬된 무방향 간선집합을 담는 원본값이다. 같은 간선집합은 같은 방문순서·반복횟수·pixel을 보장하지 않으며 정확한pixel일 때만 판정을 옮긴다.
