# Cloud2Curve 아이디어 축소 실험 (공식 재현 아님)

공식 가변 차수/다중 획 생성 모델을 재현했다고 주장하지 않는다. 이번에는 순서 불변 점 인코더에서 4개의 연결된 cubic Bezier(총12개의 학습 제어점)를 예측하고, 미분 가능한 샘플링으로64좌표를 복원하는 출력 표현만 검증한다. 폐곡선만 다루며 내부 획/펜 이동/가변 차수 없음.

기존 Quick Draw590개, 동일 manifest 분할413/88/89. 기존 점 입력 실험과 동일 uniform8/uniform16/random16, 동일 라벨 조건 입력, seed20261028,60epoch,Adam .001,batch64,MSE+.2Chamfer. 클래스 정답을 제공하므로 사물 분류 실험이 아니다. 기존 좌표출력 모델 체크포인트와 각도순 보간을 비교한다. 모델 구조의 출력층 크기는 달라 동일 파라미터 수 실험은 아니다. 원본 좌표 모델은 저장 체크포인트 재사용.

주 기준: 전체267테스트변형 Chamfer가 기존 모델보다10%이상 감소하고, 클래스별 평균이 악화되지 않으면 예비 지지. 기존 보간보다 나쁜 경우 실용 이점 보류. sparse점에서 최근접이 아닌 전체정답64점으로 평가. 원본89개 단위 paired bootstrap 2000회로 차이95%구간 기록. 테스트로 epoch 선택 금지. 원래 val로 best checkpoint 선택.

선택파일/원본해시 검증. 평가 입력은 기존 results.json의267입력을 그대로 사용하여 동일성 보장. 클래스별 첫4개 uniform8 출력 비교를 공개하며 좋은 사례만 고르지 않는다. 사람 인식/실제 도로/사진/내부선 일반화는 미측정. 앱 기본 변경 없음. 라이선스 Quick Draw CC BY4.0.
