# 10회차: 실제 스케치로 학습한 선택 모델

현재 모델은 동결 CLIP의 이름 경쟁과 수동 외곽 사전 일치에 의존한다. 새 지역 보조 다수결1/6으로 기준에 미달했다. 이번에는 후보 생성과 도로를 고정하고, 실제 손그림 예시에서 학습한 분류기가 선택을 개선하는지 비교한다.

## 데이터와 가설

공식 Google Quick Draw simplified NDJSON(CC BY4.0)에서 recognized=true이며 좌표가 유효한 각 클래스의 첫72개 고유 그림을 수집한다. 최대10000행을 탐색하고 부족하면 해당 수집 실패를 기록하며 클래스를 조용히 빼지 않는다. recognized는 게임 모델 판정이며 사람의 도로 인식 정답이 아니다. 전체 획을 사용하고 내부 특징을 임의로 제거하지 않는다.

고정 사물11종: house,tree,car,coffee cup,airplane,t-shirt,pants,hammer,wine bottle,key,chair. 고정 일반 경쟁8종: square,circle,triangle,hexagon,octagon,line,zigzag,map. 일반 경쟁은 이 모델의 추천 제외 범주이며 세상의 모든 사물 없음 정답을 대표하지 않는다. 도로 평가 이미지·3AI 판정은 학습/임계값 선택에 사용하지 않는다.

원본 그림의 정규화된 획 좌표 해시로 중복을 제거하고, 동일 원본과 모든 회전은 같은 그룹으로 묶는다. 그룹 해시로 train70%/val15%/test15%를 고정한다. 계층별 실제 분모와 중복/실패를 기록한다. 기존 apple/fish/bird 학습 세트와 클래스가 달라 원본ID가 겹치지 않아야 한다.

설치된 공식 CLIP 이미지 임베딩을 각 그림의4회전에서 추출해 L2 정규화 평균을 만든다. 같은 렌더러·처리기로 실제 도로 후보도4회전 평균 임베딩을 만든다. 원본 이미지만 사용하며 이번 회차에 새 격자 증강을 섞지 않는다. 후보 좌표와 배치각 정렬은 기존 방식을 보존한다. 평균 임베딩은 분류에 쓰고, 표시 방향은 예측 이름의 per-view 점수가 가장 큰 방향으로 선택한다.

## 학습과 대조

train 예시만 사용하는 클래스 평균 prototype 검색과 클래스 균형 ridge linear head를 비교한다. ridge lambda 후보는0.01/0.1/1/10, val macro accuracy 최고(동률 큰lambda)로 고정하고 test로 바꾸지 않는다. 입력 임베딩/목표 one-hot/학습 정규화는 train에서만 계산한다. 이 학습은 결정적이므로 seed 좋은 값 선택은 없다.

val에서 최고 클래스가 사물이고 margin 조건을 만족하는 경우만 추천한다. margin 후보0/0.01/0.03/0.05/0.1/0.2/0.4/0.8에서 일반 경쟁 오수락<=10%를 지키며 사물별 accepted-correct recall 평균을 최대화한다. 동률은 오수락이 낮은 조건, 더 높은 margin 순서다. 모두 거절하는 조건도 후보에 포함한다. calibration은 손그림 자료 한정이며 사람 인식 확률이 아니다.

보조 스케치 기준은 test macro accuracy가 prototype보다5%p 이상 높고 추천 제외 범주의 오수락이 증가하지 않는 것이다. 통과해도 실제 도로 인식 성공은 아니다. frozen text baseline과의 분류 결과도 참고 지표로 보존하되 원래v7을 유리하게 재정의하지 않는다.

## 실제 도로와 성공 판정

v9의550개 후보와 baseline2/지역을 그대로 사용한다. 원래v9 선택과 prototype/학습 head를 비교한다. 새 선택기는 전체 후보에서 사물/일반 경쟁을 분류하며 생성 가설과의 일치를 강제하지 않는다. 생성 가설 일치율과 자연 고리/생성 경로별 결과는 별도 기록한다. 이는 원래 가설 일치 gate의 ablation을 포함하는 새로운 방법이다.

지역별top2, 부족한 추천은 보류 실패, 모든 방법 분모6을 보존한다. 정확한 같은 간선 집합은 추천을 중복하지 않는다. 실제 노드·좌표·길이·반복·영역은 바꾸지 않는다. 이름/점수/방법/정답/참고 그림을 숨긴3AI 자유 명명으로 비교한다. 이미 본 지역이므로 개발 실험이며 독립holdout이라고 하지 않는다.

가시적 개발 기준은 보조 다수결 clear가 기존1/6보다2개 이상 증가(>=3/6), 도로 유효성100%, 실패/보류 분모 보존이다. 원래 단일AI 결과도 별도로 유지한다. 같은 그림은 픽셀 해시가 같으면 기존 판정을 그대로 재사용하며 새 평가나 성공으로 중복 세지 않는다. 실제 사람 인식은 별도 검증이 남는다. 기존 고정12조건·holdout-v2·앱 기본은 변경하지 않는다.

공식 자료: https://github.com/googlecreativelab/quickdraw-dataset

## 학습 전 수집 단계 수정 기록

첫 house72개 수집 뒤 split 최소 분모 검사에서 중단했다. 회전 그룹 식별자가4개 해시의 최솟값이라 앞자리가 균등하지 않은데 이를 그대로 분할에 쓴 코드 오류였다. 모델 특징 추출·학습·test 평가는 아직 실행하지 않았다. 샘플이나 클래스는 바꾸지 않고 `SHA256("split-v10:"+groupSHA256)`의 앞자리로 균등 분할하도록 고쳤다. 원본 수집 캐시는 보존하며 최종 dataset.json의 split을 권위 있는 분할로 쓴다. 평가를 보고 유리한 분할을 고른 것이 아니다.
