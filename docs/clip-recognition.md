# CLIP 인식과 모양 해석 그림

동네 추천은 `/api/recognition`에서 CLIP(`openai/clip-vit-base-patch32`)으로 외곽선을 인식한다. 브라우저는 경로의 위치를 제거한 중심·최대 폭 정규화 좌표만 전송한다. 원본 위치는 이 API에 보내지 않는다. 외부 모델 API 호출·이미지 업로드·요청 중 모델 다운로드는 없다.

현재 환경에는 실험에서 설치한 Python과 검증된 공식 가중치가 준비되어 있다. 개발 시 `eval/recognition/model-env/Scripts/python.exe`와 `eval/recognition/model-cache`를 사용한다. 다른 서버에 배포하려면 `torch`, `transformers`, `Pillow`를 설치하고 CLIP 가중치와 프로세서 파일을 미리 준비한 뒤 `CLIP_PYTHON`에 실행 파일의 절대 경로, `CLIP_MODEL_CACHE`에 Hugging Face 홈 경로를 설정한다. `scripts/clip-recognition.py`와 `src/lib/art/clipVocabulary.json`도 배포에 포함해야 한다. 이 파일·모델이 없는 배포에서는 인식이 실패하고 기존 도형 코스만 표시된다. Python과 모델은 Next.js 빌드만으로 설치되지 않는다.

첫 실행은 모델 로딩을 포함한다. 요청당 프로세스 하나를 사용하며 동시 인식은 제한한다. 128개 코스까지 한 번에 처리하고, 요청은 80초 후 종료한다. 위치 정규화 좌표도 민감할 수 있으므로 보관 로그를 만들지 않는다.

## 실험 거절 기준

345개 이름을 동일한 선 그림 프롬프트로 비교한다. 최고 이름이 제외 클래스(네모·무늬 등)면 거절한다. 최고 코사인 점수 0.30 이상이며 모든 차점(제외 클래스 포함)과의 차이가 0.003 이상일 때만 실험 이름 추천으로 표시한다. 사람 인식 확률이나 검증된 출시 기준이 아니다. 코스 배지는 확신 등급 대신 `AI 해석 · 실험`이다. DoodleNet 확률 보정값과 혼용하지 않는다. 실험의 PNG와 운영 Pillow 선 렌더러는 다르므로 운영 입력에서도 별도 평가가 필요하다.

96개 실제 경로 API 검사에서는 16개가 통과했다. 이는 16개가 사람이 알아보는 그림이라는 뜻이 아니다. 사람 평가 없이 운영 표시 기준을 보정했다고 보고해서는 안 된다. 회전·프롬프트 안정성 검증은 이번 구현에 포함하지 않았다.

## 꾸밈선

선택한 코스의 `모양 해석` 그림은 파란 실선으로 실제 경로를 보여 주고 보라색 점선으로 상상한 내부 특징을 추가한다. 꾸밈선은 켜고 끌 수 있으며 내부 클리핑으로 경로 바깥까지 새 외곽선을 만들지 않는다. 네모의 토스트 예시는 인식 결과가 아닌 상상 예시라고 표시한다. 지원 이름은 토스트·빵·토스터·휴대폰·문·망치·칼·검·톱·시소·별·왕관이다. 모든 인식 이름의 설명 그림이 준비된 것은 아니다.

설명 그림은 SVG 표시 전용이다. 지도 경로, 길이·통행 정보, 달리기 저장 좌표, GPX는 바꾸지 않는다. 꾸밈선을 추가해 인식 결과를 좋게 만들거나 사람의 자유 인식 평가 자료로 사용하지 않는다.

검증: 타입 검사·린트·138개 테스트 통과. API로 96개 경로 추론과 위치 좌표 입력 거절을 확인했고 한글 이름 전송을 검증했다. 꾸밈선 토글과 실제 좌표 불변을 컴포넌트 테스트로 확인했다.
