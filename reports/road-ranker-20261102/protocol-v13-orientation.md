# v13 진단: 선택을 고정한 표시 방향 대조

v12 head의17추천·58보류·전체75요청·점수·원본1003도로를 그대로 고정한다. 원래 고정12조건·holdout-v2·앱 기본을 변경하지 않는다. 좌표를 수정하지 않고 화면 방향만 바꾼다.

A는 v12의학습 per-view 최대 점수 표시 방향(명확4/75), B는 생성 배치의 canonical 방향(-generatorPlacement.rotDeg)이다. 같은 선택 ID의 각도를 결과 전에 모두 고정하며 사후 best-of-views를 고르지 않는다. 최종 방향을 고르기 위해 이17추천 중 좋은 사례만 재선정하지 않는다. 선택·생성 개선으로 해석하지 않는 별도의 방향 진단이다.

기존 v11과v12의 실제 RGB 본문 픽셀이 같으면3AI 원본 판정을 연결한다. 동일 픽셀의 과거 판정이 충돌하면 보수적으로 신규 검토한다. 나머지만 중립적인 파일명·무작위 토큰의 새 이미지로 이름/참고/방법을 숨겨3AI 자유 명명한다. 기존 평가자들은 이미 개발에 참여했으므로 새 독립 평가나 사람 인식 성공이라고 하지 않는다. 원래 동의어와75분모를 보존한다.

진단 지지 기준: B의 대상일치 명확 다수결이 A보다2조건 이상 증가(>=6/75), 가장 엄격한 평가자 결과도 별도 보고, 좌표·선택·보류 완전 동일. 이 기준은 v12 실패를 번복하는 새로운 성공 기준이 아니다. v12의 >=13/75 및 동물3종·사물3종 각각2지역 기준은 그대로 병기하며 현재 추천 범위로는 다양성 기준 통과가 불가능하다.

방향을 바꿔도 개선이 없으면 해당 표시 정책만으로 부진을 설명하는 가설을 기각한다. 개선이 있어도 분류 불일치로 보류된 오리 등은 회복되지 않는다. 다음 생성 연구는 과거 단일 motif/부분 가중 반복 대신 복수 특징의 실제 독립 경계·상대 배치 보존을 별도 프로토콜로 검증한다.
