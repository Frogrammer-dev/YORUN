# 가변 점 추출 사전 계획

사용자 지시: 16점 제한 제거, 특징점 보존. 기존 U2NetP 24장 마스크 고정, 분리 재실행/학습 없음.
기존 feature-points.select가 검출하는 모든 필수점을 유지한다(잡음 특징도 아직 포함). 부족한 초기점은 x/y 극점으로 보충. 원본256점 윤곽과 선택점 사이의 순서상 대응 선분 최대거리가 긴변의0.01 이하가 될 때까지 최대오차점을 추가한다. 종료 상한은 입력256점이며 임의로16/32/64에서 자르지 않는다. 이는 의미적 특징의 완전 보존 보장이 아니다.
대조: 각 그림에서 가변 방식이 사용한 것과 동일한 수의 균일점, 별도 고정16/32/64점 곡선. 원본 순서를 이용하므로 모델 복원이 아닌 샘플링 진단이다.
24개 모두 결과 보존, 분리 면적/분절 자동실패는 실패로 포함. overflow는 더 이상 실패 조건이 아니다. 기존16점 결과를 소급 변경하지 않는다. 목표: 모든 처리 가능한 외곽에서 필수점 누락0, 최대 대응 오차<=0.01, 같은 수 균일점 대비 평균 선분오차10% 개선 여부 보고. 분리 정답 품질/사람 인식/도로 성과로 해석 금지.
