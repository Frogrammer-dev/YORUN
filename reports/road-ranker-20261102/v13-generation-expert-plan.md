# v13 전문가 제안: 복수 특징의 독립 도로 경계 보존

2026-11-02. 코드·과거 기록을 읽은 설계 검토이며 실행 프로토콜이나 새 성과가 아니다. 구현·생성·모델 실행·새 평가를 하지 않았다. 원래12조건과 holdout-v2는 사용하지 않았다.

## 현재 실패를 어떻게 해석할 것인가

사용자 전달 최종 v12 AI 집계는 head clearTarget4/75(동물1·사물3), prototype1/75, 기존 v11 baseline8/75, primary0이다. 사전 성공 기준 미달이며 사람 인식은 미측정이다. 이 결과만으로 **좋은 후보가 전혀 없다거나 생성만 실패했다**고 결론 내릴 수 없다.

실제 `v12-domain-shift-audit.json`에는 분류·선택·표시의 서로 다른 병목이 있다. 전주 오리 기존 성공 후보는 t-shirt로 분류되어 해당 요청이 보류됐다. 천안 물고기는 fish로 맞혔지만 다른 ID가 선택됐다. 천안 바지·전주 바지·울산 망치는 기존 ID가 그대로 선택됐으나 표시 회전이 달라질 수 있다. 천안 바지는 canonical188.2027°→모델8.2027°(180° 차이), 전주 바지는1.0127°→271.0127°(270° 차이)다. 따라서 바지3→0 감소를 모두 기하 훼손이나 분류 실패로 돌리지 않는다. 전체1003개가 익명 의미 평가된 것도 아니므로 target pool의 빈곤은 아직 진단 가설이다.

반면 v12 target-match 선택은 동물2종·3요청(기린2·물고기1)에만 도달했다. 선택 ID·보류를 고정하면 표시 회전이 완벽해도 동물3종×2지역 기준을 충족할 수 없다. 이는 **현재 선택 정책의 도달 상한**이지 전체 후보 풀의 인식 상한이 아니다.

## 하나의 생성 가설과 최소 대조 실험

**H13:** 단일 꺾임이나 특징 구간 평균오차 대신, 서로 다른 실제 도로 사슬로 구현되는 최소 두 식별 특징의 **폭·깊이·상대 배치**를 완성 전후 유지하면, 같은 배치·예산의 제약 없는 완성보다 익명 목표 인식이 늘어난다. 사슬 통과만으로 의미 보존을 인증하지 않는다. 예: 기린의 긴 목 양 경계와 작은 머리, 오리의 부리 돌출과 목 안쪽 홈, 물고기의 꼬리 잘록함과 몸통 접합을 함께 검사한다. 새 그림 bank나 내부 장식선을 추가하는 가설은 아니다.

1. **고정 범위:** 기존 동결 v9 도로3지역, catalog 동물11+사물14 전부×3=75요청. v11/v12는 모두 개발 자료다. rocket도 생성·평가 분모에 남기고 head 미지원과 도로 실패를 구분한다. turtle/sea_turtle, mug/coffee_cup 범주 차이를 기존 정의대로 기록한다. 각25종의 기존 외곽에서 두 특징과 필수 상대 관계를 출력 관찰 전에 명시·해시 고정한다. catalog의 feature/risk 문장은 측정 결과가 아닌 구조 가설이다. 정의 불가능한 종도 삭제·대체하지 말고 설계 미지원으로75분모에 남긴다.
2. **생성 표현:** 특징마다 단일 apex가 아닌 입구–안쪽/끝–출구의 연속 도로 사슬을 찾는다. 목·귀·부리 등 두 경계에 같은 무방향 간선을 재사용해 폭0이 되는 조합을 거절한다. 서로 떨어진 특징 사슬은 내부 노드/간선 중복을 금지하고 필요한 접합점만 공유한다. 공통 몸통 좌표계에서 폭·깊이/몸통 크기, 특징 간 거리·방향·순환 순서를 검사한다. 예시 시작값으로 기준 외곽 대비 폭·깊이·거리 비율0.5–1.5, 방향 오차30° 이내를 제안한다. 이는 검증된 수치가 아니며 **실행 전 확정할 값**이다. 몸통 기준축은 끝난 경로에 다시 맞춰 제약을 사후 충족시키지 않는다. 모든 특징·연결 이동을 실제 경로에 그대로 포함한다.
3. **A/B:** 도로 기반 배치 목록과 특징 사슬 조합 목록을 먼저 공유·고정한다. A는 같은 배치에서 기존 일반 완성, B는 복수 사슬과 관계 조건을 강제하여 완성한다. 같은 목록을 쓰므로 도로 기반 배치만의 효과를 특징 보존 효과로 세지 않는다. B의 사슬 충돌·완성 불가도 실패로 기록한다. 결과 선택은 양쪽 동일한 기존 전체 외곽 기하 순위와 ID tie로 pool≤8, 최종1/요청; CLIP/head gate 없이 비교한다. 따라서 모델 재보정과 생성 효과가 섞이지 않는다. B의 제약은 실제 경로를 바꾸므로 바뀐 geometry/edge hash 수를 반드시 보고한다. 결과가 모두 같으면 새 생성 효과 없음이다.
4. **예산:** 양쪽 요청당 최대60개 공유 배치/조합 시도, A*1회당12000확장, 누적200만 확장 및15초 중 먼저 도달하면 중단하는 소규모 시작안을 제안한다. 150요청 상한은 실행 시간상 별도 배치가 필요할 수 있다. 전처리도 별도 총상한과 시간으로 사전 고정하고 공동비용으로 보고한다. 확장 상한과 시간 상한을 함께 두되 실제 소비가 같다고 주장하지 않는다. attempts60만을 이전 globalSearch와 동일 비용이라고 부르지 않는다. 제안·평가·확장·전처리·완성 시간 및 예산 소진/부분 결과/실패 이유를 분리한다. 실행 가능성 검토 후 프로토콜에서 한 번 고정하며 도중 증액하지 않는다.
5. **정밀 검증:** 그래프 snapshot/hash, path→xy/latlon 일치, 연속 실제 간선·폐곡선·영역 내부, native/projected 길이 모두3–8km, 무방향 간선 길이 기반 반복≤.2. 강제 사슬이 최종 경로에 실제 순서대로 남는지, 너비·깊이 조건이 완성 뒤에도 성립하는지 별도 재검사한다. 보기 좋게 직선 연결·스무딩·연결선 숨김 금지. 원래 점수식·shape 정의는 그대로 두고 보조 수치로 보고한다.

### 저비용 표시 회전 진단: 생성 A/B와 분리

새 생성 실행 전에 할 수 있는 진단으로, 기존 선택 ID·보류·점수는 동결하고 canonical 대 model absolute rotation만 바꾸는 표시 ablation을 제안한다. 전체 고정75슬롯을 유지하고 회전이 달라진 동일 ID만 새 익명 이미지 평가가 필요하다. 나머지 동일 픽셀은 기존 판정을 명시적으로 연결한다. 바지 등 기존 성공 사례만 골라 주효과를 계산하지 않는다. 주 평가는 canonical 한 방향으로 고정하고, 모델 회전은 부진단으로 두어 사후 best-of-views 성공 집계를 막는다. A/B 생성 그림도 같은 canonical 규칙·bbox 정규화·선 굵기를 사용한다. 이 진단의 회복은 표시 효과이며 생성 개선으로 세지 않는다. 본 문서는 실행을 요청하거나 수행한 기록이 아니다.

## 사전 반증과 평가 권고

- 기술 지지의 제안 기준:75분모에서 B의 유효 최종 경로 감소≤3건, 동물33요청 중 두 특징을 모두 충족한 출력이 A보다 최소6건 증가. 단순 목적함수 상승은 이 검사 대신이 될 수 없다. 실패별로 도로 사슬 부재/양 경계 붕괴/관계 불일치/연결 실패/거리/반복/영역/예산을 중복 기록한다.
- 의미 지지의 제안 기준: canonical 익명 자유 명명의 사전 지정 primary에서 B clearTarget이 A보다 최소5/75 증가하고, 동물 증가가 최소3/33이며 최소2종에 걸쳐야 후속 검증 근거로 삼는다. 이는 새 개발 실험 기준 제안이지 실패한 v12 기준 변경이 아니다. 기존 엄격 다양성 gate(동물3종·사물3종 각각2지역)와75전체 점수도 별도 그대로 보고한다. 보조 다수결만 개선되면 primary 성공으로 승격하지 않는다.
- 특징 충족이 늘어도 자유 명명이 그대로면 해당 특징 정의/관계가 인식의 충분조건이라는 가설을 기각한다. 유효성만 늘면 배치·연결 기술 성과로 제한한다. 유효 후보가 부족하면 이 예산·도로·제약에서의 생성 실패이지 해당 동물의 세계적 불가능성이 아니다. 일부 B 후보만 골라 모델 선택기를 붙여 성공을 구조적 효과로 바꾸지 않는다.
- 평가자는 생성에 참여하지 않은 익명 AI, 실제 사람을 구분한다. 기존3AI 피드백은 개발 근거로만 쓰며 재평가를 새 독립 증거로 부풀리지 않는다. 중복 픽셀·같은 도로 계열은 판정 재사용 및 상관을 기록한다. 양팔 추천만의 실패로 풀 전체 부재를 주장하지 않는다. 추가 풀 표본 검토는 별도 탐색 진단으로 표시한다.

**권고:** 먼저 회전 통제 진단으로 v12 감소의 일부 원인을 분리하되, 다음 생성 투자는 위 복수 특징의 독립 경계 제약 하나에 한정한다. 단일 motif 강제·arc 가중치 재튜닝·classifier-only 반복은 이번 가설의 구현이 아니다. 새 지역·실제 사람 검증 전 앱 기본 변경이나 최종 목표 달성을 주장하지 않는다.
