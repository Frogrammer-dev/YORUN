# 도로 기반 이름·참고 그림 생성

2026-10-14. 앱과 서버 연결을 구현했고 관련 51개 검증, 타입 검사, 관련 파일 lint, 프로덕션 빌드를 통과했다. 외부 API 키가 없으므로 실제 유료 호출·모델 품질·실측 비용은 아직 확인하지 않았다. 아래 설정은 앱 서버용이며 이 대화의 Codex 모델·추론 강도 설정과 별개다.

## 사용하는 방법

프로젝트 루트의 Git에서 제외된 `.env.local`에 다음 항목을 설정한다. 기존 환경 설정이 있으면 유지하고 항목만 추가한다. 실제 키를 채팅·`.env.example`·소스 코드에 넣지 않는다.

```dotenv
OPENAI_API_KEY=여기에_본인의_OpenAI_API_키
ROAD_REFERENCE_MODEL=gpt-5.4-mini
ROAD_REFERENCE_MAX_CALLS_PER_HOUR=60
```

개발 서버를 다시 시작하고 코스 찾기에서 자동 그림 발견을 실행한다. 실제 도로 경로를 먼저 표시한 뒤 최대 3개 자연 고리에서 닮은 이름과 참고 그림을 생성한다. 결과 코스를 선택하면 실제 경로, 참고 그림, 꾸밈선을 각각 켜고 끌 수 있다. 파란 실선은 달릴 길, 주황 점선은 참고 윤곽, 보라 점선은 상상해서 더한 특징이다. 저장·달리기·GPX는 원래 실제 경로를 사용한다.

키가 비어 있거나 연결이 실패하면 기존 CLIP 해석을 사용한다. 외부 모델이 `none`을 반환하면 이름 붙이기를 보류하고 기존 코스를 유지한다. 보류 후 다른 모델로 억지로 이름을 붙이지 않는다. 네모·하트 등 지정 그림 찾기와 자유 러닝 모드에는 이 외부 생성 기능을 사용하지 않는다.

`GET /api/recognition/reference`에서 `configured`를 확인할 수 있다. 응답에는 키가 포함되지 않는다. `configured:true`는 서버 설정 형식을 확인했다는 뜻이며 키의 권한·결제 상태·모델 가용성을 인증하지 않는다.

## 전달하는 자료와 출처

브라우저에서 경로를 단위 좌표로 정규화한다. 실제 위도·경도, 위치, 주소, 지도 배경, 기존 대상 이름을 보내지 않는다. 앱 서버는 정규화된 전체 실제 꼭짓점으로 512px 흑백 선 그림을 만들고, 최대 256점의 선 좌표와 함께 고정 OpenAI Responses API로 보낸다. 도로 모양 자체는 독특한 위치의 단서가 될 수 있으므로 완전 익명이라고 설명하지 않는다.

모델은 대상 이름, 설명용 벡터 윤곽, 길에서 관찰한 부분과 경로 범위, 상상으로 추가한 특징, 부족한 특징, 짧은 설명을 반환한다. 허용된 M/L/Q/C/Z 명령과 0–1 좌표만 렌더링하며 모델의 임의 SVG·HTML·URL을 사용하지 않는다. 원본 후보와 지문이 다르거나 형식이 잘못된 결과는 거절한다. 생성 결과의 구조 검증과 대상의 의미 정확성은 구분한다.

기본 모델 GPT-5.4 Mini는 이미지 입력과 Structured Outputs를 지원한다. 원격 이미지를 새로 만드는 기능을 호출하지 않고 벡터 명령을 텍스트로 받는다. [공식 모델 문서](https://developers.openai.com/api/docs/models/gpt-5.4-mini), [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=responses), [이미지 입력](https://developers.openai.com/api/docs/guides/images-vision).

요청에 `store:false`를 사용한다. OpenAI API 데이터는 기본적으로 모델 학습에 사용하지 않지만, 남용 모니터링 자료가 기본 최대 30일 보관될 수 있고 예외가 있다. `store:false`를 보관 기간 0으로 해석하지 않는다. [공식 데이터 정책](https://developers.openai.com/api/docs/guides/your-data).

## 비용과 한도

2026-10-14 확인한 GPT-5.4 Mini 표준 토큰 가격은 입력 100만 토큰당 $0.75, 출력 $4.50다. 이미지 입력도 토큰으로 과금된다. 예를 들어 입력 3,000·출력 1,000 토큰이면 1회 약 $0.00675, 3회 약 $0.02025다. 이는 계산 예시이며 이번 앱의 실측 비용이 아니다. 출력 토큰 한도에는 모델의 추론 토큰도 포함될 수 있다. 가격·가용성은 사용 시 공식 문서를 다시 확인한다. [공식 모델 가격](https://developers.openai.com/api/docs/models/gpt-5.4-mini), [이미지 과금 설명](https://developers.openai.com/api/docs/guides/images-vision).

검색당 후보 최대 3개, 자동 재시도 없음, 요청 전체 45초, 동시 배치 1개, 호출당 출력 4,000토큰으로 제한한다. 모델·프롬프트·축약 좌표·전체 실제 선 좌표가 모두 같은 결과는 프로세스 메모리에서 30분, 최대 64개 재사용한다. 성공한 새 호출의 사용 토큰을 응답으로 제공하며 캐시 재사용은 새로운 외부 호출이 없다. 실패하거나 취소된 호출도 외부에서 과금될 수 있다.

프로세스 내 이동 1시간 호출 상한은 기본 60이며 `ROAD_REFERENCE_MAX_CALLS_PER_HOUR`로 1–120을 설정한다. 서버 재시작·여러 서버 인스턴스에 걸친 지출 한도는 아니다. 공개 서비스 운영에는 사용자 인증, 공유 저장소 기반 사용량 제한, 공급자 프로젝트의 지출 관리가 추가로 필요하다. 이 변경은 로컬 앱 연결이며 공개 배포를 수행하지 않는다.

| 방식 | 비용·운영 | 개인정보 | 현재 상태 |
|---|---|---|---|
| 외부 서버 AI | 사용량 과금, 모델 설치 없이 API 사용 | 정규화 선 그림도 외부 전송됨 | 사용자가 선택한 구현, 실제 키 필요 |
| 로컬 PC 모델 | 외부 토큰 과금 대신 설치·장비·추론 시간 필요 | 추론 입력을 PC 안에서 처리 가능 | 이번 변경에는 연결하지 않음 |
| 기존 CLIP | 로컬 Python·모델 캐시 필요 | 위치 제외 선 그림을 앱 서버에서 처리 | 미설정·연결 실패 시 사용 |

## 평가와 재현

생성 reference를 실제 도로에 다시 맞춘 점수를 기존 유사도로 표시하지 않는다. 별도 `semanticExplanation`에만 저장한다. 목록 배지는 ‘AI 해석 · 참고 그림’, 참고 그림과 달리기 화면은 ‘AI 해석 · 실험’으로 표시한다. 고정 그림을 찾는 원래 점수식과 실제 경로 조건은 유지한다.

실제 6개 도로의 별도 에이전트 시제품은 4개 해석·2개 보류였고, 이름을 보지 않은 판정 recognizable 0/6, 이름·그림을 본 뒤 이름 납득도 평균 62.25였다. 같은 모델 계열의 소수 AI 판정으로 사람 인식률을 증명하지 않는다. 기본 API 모델 GPT-5.4 Mini를 실측한 결과도 아니다. 원래 12조건 자동 평균은 77.416667이며 80 목표를 달성하지 못했다. [시제품 보고서](../reports/route-improvement-20261012/road-first-reference-prototype-20261014.md).

핵심 구현: `src/lib/art/roadReference.ts`(순수 좌표·출력 검증), `roadReferenceProvider.ts`(서버 요청·캐시), `roadReferenceClient.ts`(자연 고리 선택·정규화·응답 재검증), `src/app/api/recognition/reference/route.ts`, `ShapeExplanation.tsx`. 실험 입력·실제 좌표·그림과 판정은 Git ignored인 `eval/recognition/road-first-reference-20261014/`에 있다.

검증은 순수 형식 9개, 서버 제공자 12개, API 6개, 클라이언트 8개, 새 그림 UI 3개, 저장 2개, 기존 표시 10개·꾸밈선 1개로 총 51개다. 외부 응답은 mock이며 UI는 JSDOM에서 확인했다. 다중 suite 실행의 임시 SSR 파일 ENOENT는 suite를 단독 순차 실행해 해결했고 각 검증은 통과했다. 최초 Windows 샌드박스 빌드의 경로 접근 오류는 승인된 제한 밖 실행에서 재확인해 프로덕션 빌드 종료 코드0을 확인했다. 새 `/api/recognition/reference` 경로가 빌드에 포함됐다. 실제 외부 호출과 실제 브라우저 QA는 완료하지 않았다.

별도 에이전트 검토에서 찾은 호출 비용 상한, 정규화 반올림 경계, 저장 후 잘못된 인식 퍼센트, 지연 응답 문제를 수정하고 회귀 검증했다. 서버의 구조 검증을 실제 도로 유효성이나 사람의 의미 인식 인증으로 표시하지 않는다. 실제 도로 간선·거리 검사는 기존 worker/qualitySearch 단계가 맡는다.
