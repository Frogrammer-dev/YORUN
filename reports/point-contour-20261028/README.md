# 점 조건부 윤곽 생성: 1차 구현 및 검증

2026-10-28. 사전 계획: [protocol](../point-contour-protocol-20261028.md).

## 결론
부분 점과 사물 이름에서 64점 윤곽을 학습해 출력하고 기존 도로 탐색기에 전달하는 흐름을 실제 실행했다. 그러나 이번 모델의 우월성 및 사람 인식 개선은 입증되지 않았다. H1은 사전 기준 미달, H2는 기술 연결만 확인, H3는 미실행이다. 앱 기본은 변경하지 않았다.

## 실행한 실험
- Google Quick Draw simplified 공개 자료: 사과240·물고기240·새110, 총590원본. CC BY 4.0, 출처 https://github.com/googlecreativelab/quickdraw-dataset . 각 종류 앞10000행에서 단일 획·recognized·끝점 간격 조건으로 선별했다.
- 원본 단위 분할: 학습413, 검증88, 평가89. 정규화 좌표의 정확 중복 제거. 근접 중복과 사람 기준 외곽 품질은 아직 별도 감사하지 않았다.
- 단일 획은 깨끗한 외곽선이라는 뜻이 아니다. 내부 획과 자기 교차가 포함될 수 있으며 끝점 간격 <=0.15인 원본을 닫아 정답을 만들었다. 품질 선별의 한계다.
- 이름 조건·순서 없는 점 집합 인코더(max/mean)·64좌표 디코더, CPU60epoch. 검증 기준58epoch 선택. 입력 순서 반전 불변성 확인. 새로운 평가 원본89개 ×3누락조건=267개 입력.
- 모델은 그림의 좌표열을 지도학습하고 Chamfer 항을 함께 사용한다. 특징 보존, 자기 교차 억제, 도로 연결 손실은 아직 추가하지 않았다.

## H1 결과
오차는 정규화된 좌표 거리이며 낮을수록 좋다. 인식 정확도나 백분율이 아니다.

| 방법 | 전체 평균 오차 |
|---|---:|
| 점의 각도 정렬 후 보간 | 0.034968 |
| 학습 모델 | 0.036725 |
| 같은 종류 학습 그림 검색 | 0.038366 |

검색 대비 모델 오차 감소는 약4.3%, 사전 기준10% 미달. 모델−검색 차이의 원본 단위 bootstrap95%구간은 [-0.003494, 0.000168]로0포함. 물고기는 검색보다 나빠서 종류별 비악화 조건도 미달했다.

| 입력 | 모델 | 검색 | 보간 |
|---|---:|---:|---:|
| 균일8점 | .035027 | .040317 | .042662 |
| 균일16점 | .032867 | .036170 | .023962 |
| 무작위16점 | .042280 | .038611 | .038281 |

8점의 성과는 후속 가설의 단서이지 전체 가설 성공으로 바꾸는 근거가 아니다. 균일16점에서는 보간이 우세하며 무작위 누락에서는 모델이 두 대조군보다 나쁘다.

## H2 도로 연결 진단
학습 종류와 겹치는 기존 개발 사례3개에서 저장 경로를16점으로 줄여 입력했다. 후보 점 자동 발견이 아니며 기존 도형으로 찾은 경로와 배치를 재사용한 편향이 있다. 기존 운영 전체 탐색기와의 비교도 아니다.

각 참고 윤곽을 같은 orderedContourPath에 전달했다. 동일 배치, bins32, guideWeight1.5, radiusFraction.2, 최대100000확장. 실패 포함 각 방법3회.

| 참고 윤곽 | 유효 실제 경로 |
|---|---:|
| 기존 고정 도형 | 3/3 |
| 학습 모델 | 2/3 |
| 학습 그림 검색 | 2/3 |

유효 결과는 실제 간선 연결·닫힘·영역·native/projected3–8km·양쪽 반복비율20% 이하를 검사했다. 대전 새의 학습 출력은 시작점 조건에서 탐색0회로 실패했다. 검색 출력도 해당 조건에서 경로 생성 실패했다. 조건을 사후 완화하지 않았다.

진단 그림을 직접 확인했으며 학습 윤곽에 작은 톱니와 모호한 형태가 남는다. 이는 비블라인드 개발 관찰이며 사람 인식 점수가 아니다. 모델 윤곽에 길을 붙일 수 있다는 사실만 확인했다.

## 다음 가설과 보류
1. 단일 획/끝점 조건만으로는 좋은 외곽 자료를 보장하지 못한다. 먼저 정답 외곽 품질과 자기 교차를 감사한다.
2. 좌표열 시작점의 불안정성과 독립 좌표 디코딩이 톱니를 만들 수 있다. 순환/반전 정렬 손실과 국소 연속성 제약을 비교한다. 귀·부리까지 평활화하지 않도록 별도 진단한다.
3. 부분 점 복원과 도로 입력 사이의 분포 차이가 크다. 도로식 변형 및 연결 정보는 다음 별도 사전 계획으로 검증한다.
4. 현재 최종 평가89원본은 결과가 공개됐다. 다음 튜닝에서 사용하면 개발 자료로 재분류하고 새로운 최종 평가 원본을 확보한다. 현재 성능표를 소급 변경하지 않는다.

아직 하지 않은 일: 새 지역 자동 점 선택, 연결 조건 학습(H3), 독립 사람 평가, 최종 앱 통합. 이 단계들은 이번 부정적 결과를 해결하지 않고 대규모 학습으로 넘어갈 근거가 없다.
