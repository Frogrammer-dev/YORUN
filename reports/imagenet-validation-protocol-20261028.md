# ImageNet 외곽 전처리 검증 v1 (실행 전 고정)

대상: 이미 받은 train 첫24장 전부. 편의 표본이며 학습/최종 평가용이 아니다.
질문: 별도 학습 없이 얻은 사진 외곽이 점 복원 정답으로 사용 가능한가? 특징점 보존 방식은 같은16점 균일 방식보다 외곽 근사 오차를 줄이는가?

1. 기준 분리기: OpenCV GrabCut, 최대변384, 바깥5%를 배경으로 둔 사각형 초기화, seed20261028, 5회 반복. 사물 레이블을 보지 않는 저비용 기준 방식이다. 학습된 사물 분할 모델이나 공식 위치 주석이 아니다.
2. 모든 원본·분리 마스크·외곽을 저장. 최대 외부 성분을 진단용으로 사용하되 나머지 성분 삭제량 기록. 분리 마스크를 검토 없이 정답으로 등록하지 않는다.
3. 자동 보류: 전경 비율<1% 또는>90%, 최대 성분이 전체 전경80% 미만, 외곽<8점. 전경이 사물인지 여부는 이미지별 개발 시각 감사로 별도 판정.
4. 256점 호길이 윤곽에서 동일16점 비교. feature-points.py의 두 간격40도 기준과 중복거리2 보존. 필수점>16은 실패/보류로 포함. 계산 점수는 원본256점→16점 연결 선분 평균/최대 거리(긴변1 단위). 정답 순서를 이용한 연결은 점 선택 자체의 진단이며 모델 추론 결과가 아니다.
5. 전처리 통과 문턱: 24개 중20개 이상이 주 사물의 주요 부분을 보존하고 배경 혼입이 크지 않은지 개발 시각 감사. 자동 검사 통과와 시각 통과를 혼동하지 않는다. 실패하면 이 마스크로 모델 학습하지 않는다.
6. 점 선택 가설 잠정 지지: 자동 유효 사례에서 평균 오차10% 이상 감소하고 누락/overflow 포함 커버리지 악화 없음. 이 결과는 기하학 진단이며 사람 사물 인식 개선을 의미하지 않는다.
7. 실패도 포함한 결과·비교 화면·코드·환경 저장. 원본24개 전부 분모. 결과 보고 기준을 변경하지 않는다. 실제 도로 성능은 이번 전처리 검증과 별개다.

## v1 실패 확인 후 후속 비교 (추가 모델 실행 전)
GrabCut 자동 유효8/24, 조건부 평균 오차는 특징점이 더 높다. 동일24장은 이후 개발 자료로 유지한다. 경량 사전학습 U2NetP(rembg)로 배경 분리만 교체한다. threshold127, 같은 최대384해상도, 같은 점 추출/검사/20개 시각통과 기준을 유지한다. 사용자 자료로 U2NetP를 재학습하는 실험은 아니다. 학습된 배경 제거도 사물 레이블 조건부 분할이 아니므로 주 사물을 고른다는 보장은 없다.
