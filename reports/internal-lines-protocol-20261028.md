# 외곽+내부 선 표현 실험 v1

고정 입력: 기존 ImageNet train24장 및 저장 U2NetP 마스크. 배경 분리 품질은 개선됐다고 가정하지 않는다. 반쯤 열린 통조림 정답/뚜껑 주석은 이 세트에 없으므로 해당 사례 해결을 주장하지 않는다.

비교: A 외곽만, B 외곽+마스크 내부 Canny, C 외곽+서로 다른 흐림 강도에서도 유지되는 내부 Canny 선. 최대변384, sigma1/2/3, Canny50/120. sigma1 선 중 sigma2/3에서2px 이내인 선만 유지. 마스크3px 침식 내부만 사용하여 외곽 중복 억제. 연결 성분 길이>=최대변3%만 보존. 이 기준은 의미적 중요도 모델이 아닌 잡음 억제 가설이다.

24개 전부 처리. 선량 감소/단절/분기/대표 실패를 보고한다. 정량 처리 성공과 사물 인식 성공은 구분한다. 최종 사람이름없는 평가 전 인식 향상 주장 금지. 개선 판단은 보류 가능하다.

벡터 출력: 외곽과 내부 선을 별도 stroke로 저장. 픽셀 골격의 끝점·분기점 사이를 연결 관계로 추적하고 독립 고리는 별도로 보존. 서로 다른 획을 직선으로 강제로 연결하지 않는다. 이는 이미지 그래프이며 실제 도로 연결이 아니다. 도로 반영/모델 학습/앱 적용은 이번 실험 범위 밖이다.
