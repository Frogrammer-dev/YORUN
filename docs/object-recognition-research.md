## 성공의 의미

이름, 목표 그림, 꾸밈선 없이 실제 도로 경로를 보았을 때 사물이나 동물로 알아볼 수 있어야 한다. 네모·다각형만 알아본 결과는 사물 인식 성공에 포함하지 않는다. 기하학 점수, 모델 확신도, 이름을 알려준 뒤의 납득도는 각각 보조 지표다.

현재 개발 6조건은 기하학 평균 74.6354까지 개선했지만 별도 같은 계열 AI의 원본 판정은 명확한 사물 인식 0/6이다. 이는 인간 인식률도 전체 도로 후보의 가능성 상한도 아니다. 근거는 `../reports/relation-generation-results-20261021.md`.

## 반복 실험 규칙

1. 실행 전에 가설, 비교군, 고정 자료, 계산 예산, 성공·실패 기준을 기록한다.
2. 실제 간선·연결·거리·반복·영역을 검사한다. 원래 벤치마크 제약을 바꾼 실험은 별도 실험으로 표시한다.
3. 생성과 선택에 쓰는 의미 판정은 개발용이다. 최종 평가자에게 이름·점수·방법·정답·이상적 참고 그림을 노출하지 않는다. 같은 경로 변형을 나란히 보여주는 진단과 독립 평가는 구분한다.
4. 자유 명명을 먼저 받고, 명확/약한 연상/없음을 기록한다. 생성 가설과의 일치 및 다른 사물로 일관되게 인식된 경우를 구분한다. 동의어와 판정 기준은 결과를 보기 전에 고정한다.
5. 추천된 경로 중 명확한 인식 비율과, 전체 검색 요청 중 그러한 결과를 하나라도 제공한 비율을 함께 기록한다. 아무것도 추천하지 않는 방식으로 정확도가 높아 보이지 않게 한다. 실패·보류·비용·시간·지역별 결과를 포함한다.
6. 소수 개발 표본의 개선만으로 일반화나 인간 정확도를 주장하지 않는다. 후보 선정이 끝난 뒤 새 지역과 사람 평가로 재검증한다. holdout-v2는 별도 계획 없이 튜닝에 사용하지 않는다.
7. 매 회차 결과와 비판을 남기고 가설을 유지·수정·폐기한다. 인식 성과 없는 기하학 점수 개선만으로 앱 기본을 교체하지 않는다.

## 현재 작업 방식

2026-11-02 사용자 요청으로 AI 전문가 에이전트 협업을 재개했다. 현재 작업 범위는 실제 도로 후보 선택 모델의 구현·대조 실험·익명 자유 명명 검토이며, 이번 요청의 작업에 한해 전문가와 독립 AI 검토자를 사용할 수 있다. 사람 평가와 AI 대리 지표는 계속 구분한다. 실험 계획/실패/산출물은 `../reports/road-ranker-20261102/`에 기록한다.

같은 날9회 구현·검증 후 연구 시제품과 사람 검토 화면을 제공했다. 원래 단일AI 명확0/6, 보조 다수결은 개발2/6·새 지역1/6이며 목표 기준 미달을 보존한다. 실제 사람 검증 전 최종 목표 달성이나 앱 기본 교체를 주장하지 않는다. 망치 예시의 지역·간선 중복과 평가자 불일치도 [보고서](../reports/road-ranker-20261102/README.md)에 남겼다. 다음 연구는 낮은 제공률을 출발점으로 삼고 원래 기준을 낮추지 않는다.

2026-10-27 사용자 요청으로 모든 하위 에이전트 협업 지시와 필수 역할 배정을 취소했다. 사용자가 다시 명시적으로 요청하기 전까지 단독으로 작업하며 하위 에이전트를 생성하거나 재개하지 않는다. 아래 협업 기록은 과거 결과이며 재실행 지시가 아니다. 비판적 검토와 사용자 관점 검토는 단독 작업에서 수행하되 독립 평가자 검증으로 주장하지 않는다.

## 다음 검증 가설 초안

H1: 전체 외곽 평균 오차보다 사물의 식별 특징 보존이 인식을 좌우한다. 기존 실제 경로에서 부족한 식별 특징을 먼저 진단하고, 특징 제약 생성과 동일 예산의 기존 생성을 비교한다. 점수만 오르고 익명 자유 명명 성과가 그대로면 지지하지 않는다.

H2: 항상 폐곡선 외곽만 만드는 표현이 일부 사물에 불리하다. 기존 제약 안의 연결된 내부 구간을 이용하는 방식과 외곽만 이용하는 방식을 비교할 수 있는지 먼저 확인한다. 반복률·거리 제약 완화가 필요하면 원래 성능과 섞지 않는다. 내부 획을 늘렸다는 이유만으로 성공으로 보지 않는다.

이 문서는 운영 지침과 검증 계획이며 H1/H2의 성능이 입증됐다는 보고서가 아니다.

## 첫 협업 검토 결과

비판적 검토자는 기하학 개선에도 명확 인식 0/6이 유지되고 추가 수선 이득이 정체됐으므로 동일 수선 반복의 우선순위를 낮추라고 제안했다. 복수 사물 가설을 경쟁시키고 보류하는 대안도 제시했다. 이 대안은 반환 정확도와 검색 요청 성공률을 함께 개선하는지 확인해야 한다.

비전문가 관점 검토자는 비교 그림이 사물보다 불규칙 구역 경계로 보이며, 수정 후에도 결정적 특징이 새로 생긴 것으로 보이지 않는다고 지적했다. 도로망의 짧은 식별 특징을 먼저 찾고 주변 형태를 완성하는 접근을 제안했다. 이 검토자는 이전 대화의 대상명을 상속했으므로 블라인드 평가나 독립 정확도 수치로 사용하지 않는다.

다음 구현 실험의 우선순위는 H1이다. 식별 특징을 먼저 확보하는 생성 방식, 특징 제약을 제거한 대조군, 기존 생성기를 동일 예산에서 비교한다. H2 및 복수 가설 경쟁은 별도 후속 가설로 보존한다. 현재 회차에서 새 생성 성능 실험을 실행한 것은 아니며, 성능 향상은 아직 입증되지 않았다.
