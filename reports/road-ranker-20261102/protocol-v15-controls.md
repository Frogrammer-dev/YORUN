# v15 입력 표현 진단: 원본 외곽·손그림 대조

실제 도로 v14는 A3/B2 target-clear/75,동물0이었다. 다음 생성 가중치를 바꾸기 전에 원래 목표 표현의 모호함과 도로 변환 손실을 분리한다. **이 진단은 실제 도로 개선·사람 성공을 증명하지 않는다. 양성으로 사전 검증된 표본이라는 뜻도 아니다.**

원래25종 템플릿 외곽25장,기존 v12 test split의 추천24범주 각 고정 그룹해시 순 첫2개 손그림48장,일반경쟁8범주의 test 고정 그룹해시 순 첫2개16장,총89장을 고정한다. 계획 손그림50장 중 로켓2장은 미지원으로 따로 남긴다. 실제48장 관측과 계획50장 지원 분모를 구분하며 미지원에 가짜 이미지나 none 답을 넣지 않는다. 모든 획을 사용하고 내부 눈/손잡이 등을 지우거나 획 사이를 잇지 않는다.

test split은 학습에서 제외됐지만 기존 성적을 이미 본 자료이며 새로운 독립 holdout이 아니다. recognized는 원래 게임 모델의 판정이고 사람의 인식 정답이 아니다. turtle=sea_turtle,mug=coffee_cup 관련 범주 차이를 보존한다. 손그림 표본은 결과를 보고 고르지 않는다. 현재 자유 이름 동의어를 그대로 사용하고 새로운 동의어를 추가하지 않는다.

모든 입력은 같은300px 흰 바탕,3px 진한 선,긴 축260px,bbox중심,원래 정방향으로 렌더링한다. 참고 외곽25개와 손그림/경쟁은 같은 방식으로 섞고 seed2026110315로 무작위 Q토큰을 부여한다. 이름/범주/방법/참고 설명은 평가자에게 숨긴다. 사물명을 강제로 고르게 하지 않고 자유 명명 clear/weak/none을 받는다. 세 AI의 원본 판정과 다수결을 각각 보존하며 실제 사람으로 간주하지 않는다.

진단 분기 기준: 템플릿 target-clear>=18/25이고 손그림>=36/48이면 입력 표현은 이AI 진단에서 대체로 읽히므로 도로 변환·선택 병목을 우선 검토한다. 템플릿<18이고 손그림>=36이면 단일 외곽 표현의 모호함을 우선 검토한다. 손그림<36이면 표본 모호함·평가자 기준·표현 차이를 구분할 근거가 부족하므로 AI가 틀렸다거나 사람도 못 읽는다고 단정하지 않는다. 모든 경우 가장 엄격한 평가자의 원본과 범주별 소수 분모를 유지한다.

일반경쟁 clear는 별도 해석으로 기록한다. map처럼 구체 사물로 볼 수 있는 경쟁 범주가 있으므로 이를 실제 사물 없음 정답이나 도로FPR이라고 부르지 않는다. 템플릿·손그림을 읽는 성과를 실제 도로75조건의 분자에 더하지 않는다. 원래12조건·점수식·holdout-v2·75분모·앱 기본을 변경하지 않는다. 원본 판정 뒤 이름 있는 진단과 사람 검토 화면을 제공한다. 결과로 threshold나 test split을 재조정하지 않는다.

실행 전 전문가 검토 반영: 아직 렌더링·새 판정을 실행하지 않은 상태에서 generic은 범주당2개(16장),총89장으로 고정한다. H/G 모두 (SHA256("v15-control-v1|"+groupSHA256+"|"+id),id) 순 최초2개를 선택해 ID 순서 편향을 줄인다. 동등 범주 비교는 로켓 제외24범주별 T1장/H2장 평균을 별도로 보고한다. 기존 primary를 교체하지 않고 primary의 H>=36/48·동물H>=16/22,T>=18/25·동물T>=8/11도 별도 진단선으로 기록한다. 본문의 보조 다수결 분기는 primary 통과나 도로 성공을 뜻하지 않는다.

primary의 실제 도구 agent ID는01a19aed-73d8-7662-81ef-5d6ec2287589로 고정하며 CLI 입력 순서로 바꾸지 않는다. 각 범주 내 원본 groupSHA가 다른 예시만 고르고 범주 간 같은 그룹도 거절한다. montage와 개별 Q이미지 해시를 모두 확인한다. clearAny는 같은 이름 합의가 아닌 두 명 이상의 clear 응답 수다. targetClear만 고정 동의어 일치를 요구한다.
