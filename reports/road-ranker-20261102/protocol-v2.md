# 2회차: 넓은 사물 사전과 회전 일치

1회차의 seed17/29 보조 기준은 모두 충족되지 않았다. 실도로 익명 AI 평가에서도 명확0/6 대 0/6이다. 추가 epoch나 같은 test 성능 최적화를 반복하지 않는다.

가설: 세 가지 사물에 한정된 분류기는 실제 도로에 존재하는 다른 사물 형태를 놓친다. 이미 설치된 공식 CLIP의 기존345개 이름과 제외 클래스 전체를 유지하고, 도로의 4방향 회전을 비교하는 지역 후보 선택기를 구현한다. 데이터는 동일360개로 고정한다. 도로 좌표/거리/반복/영역은 그대로 보존한다.

선택 정책은 기존 앱과 같은 cosine>=0.30, 다른 모든 이름 대비 margin>=0.003이며 제외 클래스가 최고면 거절한다. 각 회전의 점수/마진을 모두 보존한다. 후보별 회전 중 정책을 통과한 최고 cosine의 방향을 선택한다. 최고점 동률은 작은 회전 순서로 고정한다. 이는 회전 다중 탐색이므로 false positive 증가 위험이 있으며 사람 확률로 취급하지 않는다. region별 top2, 거절 슬롯 포함 분모6, 반환순 baseline2를 고정한다.

가시적 AI 대리 개선 기준은 이전과 같이 명확 +2/6, 실제 도로 유효성100%이다. 후보 선택에 관여하지 않은 익명 자유명명 AI 평가자에게 이름/점수/방법을 숨긴다. 회전은 길의 모양 해석을 돕는 균일 표시 변환이며 실제 GPX 좌표를 바꾸지 않는다. 원래 방향도 진단에 보존한다. 모든 기존 baseline은 원래 방향 표시를 유지한다. 이전 평가와 같은 후보/방향은 재활용하고 회전본 판정은 같은 경로의 변형으로 표시한다.

새 학습 모델이 아닌 동결된 모델의 실제 도로 선택기 실험이다. 같은360개는 개발 자료로 취급한다. 성공해도 신규 지역/사람 평가가 남는다. 최종 제품 모델의 완료를 뜻하지 않는다.
