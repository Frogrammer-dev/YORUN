# 도로 꺾임 기반 배치: 결과와 반증

2026-10-28. 사전 규칙: `reports/road-motif-protocol-20261028.md`. 기존 개발6조건에서 실시한 기술 실험이다. 원본 고정12조건 점수, 앱 기본, holdout-v2는 변경하지 않았다.

마지막 행은 첫 두 방식의 결과 확인 뒤 사전 기록하고 실행한 사후 대조 실험이다. 새 방식은 대구 자동차에서 다양성 필터 후 후보9개뿐이었다. 나머지는 각각27개. 도로 꺾임 탐색 전처리는 추가 비용이다. 동일 후보 상한이지 동일 시간/전체 계산량 비교는 아니다. 저장된 preprocessingMs는 그래프 구성과 도로 후보 생성 합계이며 각 방법 행에 반복 기록했으므로 합산하면 중복이다. 기존 배치 대조는 도로 후보 생성 자체가 필요 없다.

## 가설 판정: 일부 기술 성과, 전체 가설은 수정

도로 구조에 맞춘 위치·회전·크기 선택으로 유효 경로가 5/6에서6/6으로 늘었다. 하지만 공통5조건의 오차는 핵심 강제 방식에서 약24.9% 증가했다. 최초 성공 조건(성공 증가와 오차 비악화)을 만족하지 못했다. 기존 v1의2/6과는 배치 탐색 및 선택식이 달라 직접 향상률로 비교하지 않는다.

같은 도로 배치에서 사슬 강제를 없애도6/6이다. 사슬 강제의 선택오차는 제거 방식보다4조건에서 나쁘고2조건에서 같다. 따라서 **성공 증가를 핵심 구간 강제의 성과로 해석할 수 없다.** 사슬 보존보다 배치 자유도가 기여했을 가능성이 크다. 다만 대조군과 도로 방식의 위치/회전/크기 범위가 달라, 도로 꺾임 탐색이 일반적인 넓은 배치 탐색보다 우월하다는 인과 결론도 내리지 않는다.

선택오차는 도로 노드→기준 선분, 기준 꼭짓점→도로 선분의 대칭 평균/scale이다. 노드 밀도에 영향을 받고 길이 균일 샘플 평가가 아니며 원본 점수식이나 사물 인식률이 아니다. 생성과 선택에 사용한 지표를 독립 평가처럼 사용하지 않는다.

## 시각 진단

18결과(실패1개 포함)를 한 장으로 확인했다. 많은 결과에 왕복 돌출선과 계단 모양 경계가 남고, 일부는 사물보다 긴 불규칙 블록처럼 보인다. 이는 대상명을 이미 알고 수행한 AI 개발 진단이며 사람 블라인드 평가나 정확도 측정이 아니다. 기준 그림의 의미 검증도 여전히 없다. 유효 출력6/6을 사물 인식6/6으로 보고하지 않는다.

## 다음 개선 방향

핵심 세 점 하나만 맞추는 강제 방식은 기본 채택하지 않는다. 도로 기반 배치 후보는 유지할 가치가 있지만, 전체 윤곽과 복수 특징(예: 부리-몸통-꼬리)의 상대 위치를 함께 제한해야 한다. 다음 실험에서는 같은 도로 배치 후보에서 (1) 일반 완성 (2) 불필요한 왕복 구간 제거를 비교해 추가 잔가지를 줄일 수 있는지 먼저 검증한다. 제거 전후 거리·연결·핵심 구간 보존을 모두 재검사하고, 3km 미달이면 실패로 남겨야 한다. 원래 도로 길이를 줄여놓고 같은 성능으로 주장하지 않는다. 복수 특징 제약의 효과는 이 실험으로 입증되지 않았다.
