# 전문가 검토 반영: 여러 획 복원 실험

이번 사용자 요청으로 AI 전문가 하위 에이전트1명과 설계 검토. 과거 필수 역할2명 지시는 재개하지 않는다. 적용 대상은 실험 학습 파이프라인이며 검증 전 앱 추천 기본은 교체하지 않는다.

데이터: 공식 Quick Draw simplified apple/fish/bird 각최대300개,2획이상. 기존590개ID 제외, recognized는 게임 인식 여부이지 사람 품질 보증 아님. 최대10000줄/범주 스캔. 모든 획 유지, 실제 유효좌표가 없는 획을 가진 그림은 사유 기록후 제외. 원본 좌표 중복제거 후 연속 중복점만 제거, 전체 그림 bbox정규화, 그림 해시로중복검사. 그림단위 hash70/15/15분할. 변형은 split후 생성.

관측 가정: 획 구분 및 획 안의 순서가 주어짐. 모델/보간 모두 동일 정보 사용. 실제 도로에서는 자동 획 분할이 별도 필요. 사물명/라벨 입력 없음. 획 수 제한과 연결선 추가 없음. 점 하나 획은 점으로 보존. 열린 resampling은 끝점을 포함하며 원래 펜 이동을 연결하지 않는다.

각 획 target은32개 호길이점으로 근사(아주 작은 내부 구조 소실 가능). target에서 양끝+40도 이상 코너를 보존, 나머지 점은 mild stride4 / sparse stride8으로 줄임. 점수 고정16제한 없음. 코너는 의미상 핵심점 보증이 아니며 입력을 만드는 oracle sampling 가정이다. 입력점은 순서대로 호길이 보간하여32개 baseline. 잔차 모델: baseline flattened64 + 관측된 그림전체점을 max/mean pooling한 context→64좌표잔차. 양끝은 고정. 대상/정답선/정답class는 context로 전달하지 않음.

seed17/29,30epoch,batch128,Adam.001,MSE 학습. 모델은 실제 출력점이 아닌 보간의 잔차를 예측한다. val그림별평균 Chamfer로 선택. test그림별(획별 균등평균) Chamfer와 획별 endpoint오차, class별/mild/sparse를 보고. 주 기준: 두 seed 모두 전체그림오차 보간대비10%이상 감소 및 클래스별 비악화. 실패면 모델채택 보류, 다중획 데이터 표현/출력은 유지. 원본 그림을 분모로 사용, 많은 획의 그림이 평균을 독점하지 않도록 함. 사람 인식/도로 실현은 미평가. split별 ID 및 hash 누출검사, synthetic 열린선/두획/점획 검증.

실행 중 전문가 코드 검토 반영: 점 하나 획은 모델의 모든 잔차를0으로 고정해 점을 가짜 선으로 바꾸지 않는다. 관측 코너 보존은 입력선정까지이며 출력의 내부코너 위치 보존은 보장하지 않는다(끝점만 고정). 짧은 획(정규화 호길이<.15) 오차를 별도 보조 진단하되 성공 기준은 변경하지 않는다. 점획 수정 후 동일 설정으로 재학습하며 이전 실행값은 채택하지 않는다.
