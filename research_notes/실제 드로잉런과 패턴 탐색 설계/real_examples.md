# 실제 러너의 GPS 드로잉 작품과 제작 과정 조사

조사일: 2026-10-21. 범위: 작품·제작 과정의 공개 1차 자료. 앱 코드 변경, 유료 API 호출, 새 알고리즘 평가, 홀드아웃 접근은 하지 않았다.

## 1. 실제 작품에서 어떤 시각·경로 구조가 보이는가?

### Takeaway

Gene Lu, Lenny Maughan, Jeric Yuen의 러닝 작품 6개를 공개 원본 이미지 또는 공식 Strava 페이지/공개 활동 embed에서 직접 보았다. 단순 하트 윤곽과 달리 얼굴·문자·복잡한 사물은 내부 획과 부품의 배치가 의미를 만든다. 모든 그림은 이름·설명을 먼저 본 뒤 관찰했으므로 블라인드 인식 성공률 자료가 아니다.

### Cited Findings

위 6개는 모두 지도 배경이 있는 경로 표현이다. 지도 없이 깨끗한 단색 선만 보여 준 실험을 실시한 것은 아니다. 원본 데이터 다운로드·복제·이미지 재배포는 하지 않았다.

### Inferences

- **설계 가설:** 어떤 그림은 하나의 실루엣으로 충분하지만, 얼굴·문자·복잡한 사물에는 부품 그래프가 필요할 수 있다. 전체 외곽 평균 오차만 줄이는 전략은 작은 눈·귀·오목부 같은 의미 있는 부분을 희생할 가능성이 있다. 이는 관찰에서 나온 가설이고 새 모델의 성능 입증이 아니다.
- **설계 가설:** 격자 도로에서 매끈한 곡선이 아니어도 핵심 부분의 위치·비례·방향이 유지되면 설명 가능한 모양이 될 수 있다. 반대로 같은 원·네모라도 내부 특징이 없으면 구체적인 이름의 근거가 약할 수 있다.
- **평가 함의:** 보이는 선의 집합과 그 선을 실제로 달리는 순서는 별도로 다뤄야 한다. 사진에서 내부 선이 보인다는 이유만으로 자유로운 펜업 또는 무한 반복 허용을 도입해서는 안 된다.

### Gaps

- 이 표본에서 **3~8 km이며 실제 연결 도로·낮은 반복률까지 확인한 작품은 확보하지 못했다**. 공개 성공작 대부분이 장거리인 이 표본으로 짧은 작품이 불가능하다고 결론 내리면 안 된다.
- Gene 작품의 개별 날짜·GPX·전체 경유점, Lenny/Jeric의 pause 구간·GPS 정제·숨김 구간은 확인하지 못했다. 본인의 러닝 프로젝트 설명 또는 Run 카드와 원본 파일의 독립 검증은 서로 다르다.
- 제목을 알고 본 관찰이고 사람이 참여한 블라인드 평가가 아니므로 “대부분 사람이 알아본다”, “인식률 80%”라고 쓰지 않는다.

## 2. 창작자들이 실제로 어떤 방식으로 계획하고 실행하는가?

### Takeaway

공개 제작 설명은 우연한 고리에 이름을 붙이는 일만으로 끝나지 않는다. 상징적인 부분을 먼저 정하고 지도에서 찾기, 전체 배치 수정, 실제 이동 순서 계획을 결합한다. 다만 창작자별 자유도가 앱의 엄격한 연속 도로 조건과 같지는 않다.

### Cited Findings

- Gene Lu 본인 설명: 간단한 스케치를 한 뒤 가장 상징적인 부분을 골라 지도에서 찾는다. 디지털 경로로 바꾸며 거리와 회전을 확인하고, 실행 전에 회전 안내 카드를 만든다. [본인 제작 과정](https://genelu.com/work/gps-art-running)
- Lenny가 공식 Strava 인터뷰에서 설명한 과정: 지도 속 모양을 먼저 발견하거나, 정한 그림을 지도에 맞춘다. 많은 초안을 검토하며 교차·왕복도 허용하고, 시작·종료 위치로 불필요한 왕복을 줄인다. 장애물에서 녹화를 멈추고 우회한 뒤 재개하면 두 기록점 사이에 직선이 표시될 수 있다고 밝힌다. **이 설명은 특정 표의 작품에 pause가 실제 사용됐다는 증거는 아니다.** [직접 인터뷰](https://stories.strava.com/ea/articles/love-strava-art-how-to-create-your-masterpiece)
- Jeric Yuen의 인터뷰 녹취: 쉬운 10 km 그림도 계획에 약 2시간, 큰 30 km 그림은 약 4~5시간 걸리는 경우가 있다고 말한다. 디지털 지도에서 경로를 계획한다고 설명한다. 이는 개인의 자기 보고이며 전체 창작자 평균이 아니다. [본인 출연 인터뷰 녹취](https://zencastr.com/z/cFXV6jbm)
- Lenny의 Heart Hands는 한 사람이 모든 그림을 달렸다고 보기 어려운 별도 예다. 본인 활동 설명이 친구 Frank Chan의 서쪽/왼손과 자신의 동쪽/오른손 협업을 명시한다. 카드의 **20.1 mi, 4h 17m**은 Lenny 자신의 활동 값이다. 이 작품의 그림은 이번 조사에서 직접 보지 않아 시각 평가 표에 넣지 않았다. [본인 활동](https://www.strava.com/activities/7831032592), [친구의 활동 링크](https://www.strava.com/activities/7831179927)
- 이동수단 혼동 주의: 공식 Strava는 Tim Lewin의 점박이 기린을 **6회 자전거 활동의 합성**이라고 설명한다. 러닝 단일 활동 성능의 근거에서 제외한다. 그림 자체는 이번 조사에서 직접 확인하지 않았다. [공식 설명](https://stories.strava.com/articles/the-best-strava-art-of-2023)

### Inferences

- **설계 가설:** `지역 도로의 특징 찾기 → 의미 있는 부품 가설 → 부품의 위치·비례·전체 모양 조립 → 실제 연속 경로로 실행 가능성 확인`을 반복하는 방식이 인간의 공개 계획 과정과 더 가깝다.
- **설계 가설:** 이름 후보 또는 사전 도형을 하나로 고정하기보다 여러 대상·부품 가설을 경쟁시켜 도로가 잘 지원하는 조합을 고르는 실험이 타당하다.
- **설계 가설:** 새 표현을 만들더라도 앱에서 실제 달릴 도로 선, 해석을 돕는 꾸밈선, 표시에만 나타나는 기록 공백 직선을 서로 혼동하지 않게 해야 한다.

### Gaps

- 창작자가 공개한 작품마다 검토했던 실패 초안·총 후보 수·이동 장소 선택 범위는 알 수 없다. 인간 작품에 몇 초의 자동 탐색과 동일한 시간·공간 예산을 가정할 수 없다.
- 원본 GPX 없이 펜업, 왕복, 복수 활동, 진입 이동을 분류한 학습 라벨을 만들면 오류가 생길 수 있다. 이번 조사에 원본 GPX는 수집하지 않았다.

## 3. 표본 편향과 한국 사례를 어떻게 해석해야 하는가?

### Takeaway

유명 완성작의 성공 조건을 일반 사용자에게 그대로 요구해서는 안 된다. 단순 윤곽형이 맞는 영역을 남기고, 복잡한 작품의 표현력 확대는 별도 검증해야 한다. 국내 사례는 1차 실행 실패 후기까지 확인했으나, 이번 범위에서 완성 그림의 시각·거리·도로 연속성을 함께 검증한 국내 표본은 확보하지 못했다.

### Cited Findings

- 수집 경로 자체가 `best` Strava 공식 선집과 창작자 포트폴리오다. Strav.art도 선별된 작품만 갤러리에 실린다고 명시한다. 따라서 무작위 일반 러닝 결과의 분포가 아니다. [공식 선집](https://stories.strava.com/articles/the-best-strava-art-of-2023), [갤러리 선별 안내](https://www.strav.art/)
- 국내 본인 작성 실패 후기(익명, 독립 사실 검증 불가): 여의도 고구마런을 시도했으나 갈림길에서 다른 방향으로 가고 되돌아 뛰었으며 종아리 통증으로 종료했다고 설명한다. 어둠·보행로 연결·자전거와의 혼잡이 언급된다. **본문만 T 확인했고 첨부 경로 이미지 픽셀은 직접 보지 않았으므로** 모양·거리·반복률 판정에 쓰지 않는다. [본인 공개 후기, 2024-09-02](https://gall.dcinside.com/mgallery/board/view/?id=running&no=402039)
- 한국의 아트런 캔버스 자체 안내는 실제 길 연결과 별도로 눈·코 등 떨어진 부분 사이의 `이동(점선)` 표시 기능을 설명한다. 이는 해당 도구의 기능 설명이며, 실제 러너 완성작이나 기능 사용률의 증거는 아니다. [서비스 자체 안내](https://artruncanvas.com/info)

### Inferences

- **검증 가설:** 표본을 `짧은 단순 윤곽`, `짧은 내부 특징`, `장거리 복합`, `문자`, `합성/펜업`, `실패/애매함`으로 나누고 비교해야 자동 추천의 실제 개선을 평가할 수 있다. 원래 12조건은 그대로 유지하고 새 축은 별도 평가로 둔다.
- **검증 가설:** 블라인드 원본 선 평가와 제목 공개 후 평가, 꾸밈선 공개 후 평가를 구분해야 사후 설명 능력을 모양 발견 성능으로 오인하지 않는다.
- **균형:** 단순 하트·상징 같은 윤곽형에는 현 방식이 자연스럽다. 내부 획·분기 구조의 확대가 모든 경우에 이득이라는 근거는 없고, 반복률·거리·안내 난도와의 교환 관계를 실험해야 한다.

### Gaps

- 국내의 짧은 연속 러닝 완성작을 공개 GPX까지 포함해 검증하는 후속 수집이 필요하다. Instagram 로그인·접근 장벽을 우회하지 않았으며, 검색 결과 제목만으로 작품을 보았다고 기록하지 않았다.
- 이번 목적은 설계 논의의 근거 확보다. 점수 개선, 사람 평균 인식률, 국내 도로에서의 성공률을 새로 측정하지 않았다.
