# 발견형 추천("~처럼 보이는 테두리") — 기존 기술의 응용 가능성 조사

2026-10-23. 직접 데이터셋을 만들지 않고, 이미 구현됐거나 유사한 기술에서 가져올 수 있는 것을 정리했다. 웹 페이지 요약 도구로 읽은 내용이며, 논문 전문을 모두 검증한 것은 아니다. 읽지 못한 부분은 각 항목에 적었다. 기존 `research_notes/이미지 인식 경로 추천 개선/models.md`(CLIP·SigLIP 2·Sketch_LVM·서버 VLM 비교)와 겹치는 내용은 줄였다.

## 1. 가장 중요한 발견 세 가지

1. **기존 GPS 아트 도구는 전부 "그림 → 경로" 방향이다.** RouteDoodle, GPSArtify, RouteSketcher, Draw My Loop 모두 사용자가 그림을 정하고 도로에 맞춘다. 이번에 읽은 자료에서는 "도로에서 닮은 모양을 먼저 발견"하는 제품이나 논문을 찾지 못했다. (읽은 페이지에 없다는 뜻이며, 없다는 증명은 아니다.)
2. **TU Delft 석사 논문(2023)이 우리와 같은 문제 구조를 이미 실험했고, 3~8km 구간이 가장 불리하다고 보고한다.** A* 경로 탐색, 템플릿 매칭, 스케치 분류기로 인식 가능성을 근사하는 방식이다.
3. **구름 속 동물 연구 "Diamonds in the Sky"(2026)가 발견형의 사용자 효과를 가장 직접 시험했다.** 모양에 맞춘 "도움 그림"을 보여 주면 사람이 알아보는 정도가 올라갔다.

## 2. 기술별 정리

### 2-1. TU Delft 석사 논문: GPS 아트 생성 (Powałka, 2023)
- 방법: 고정 배치는 A*에 거리+유사도 비용, 배치 탐색은 OpenCV 템플릿 매칭 + 크기·회전·전단 전수 탐색, 후처리로 Douglas-Peucker 및 U턴 제거.
- 평가: RTMV(기하 편차/길이), QuickDraw로 학습한 분류기의 "정확한 라벨 비율"과 확신도, LPIPS. **사람 평가는 없다.**
- 결과(분류기 기준, 자전거·코끼리·손): 도쿄 89%, 암스테르담 78%, 뉴욕 44%, 파리 33%, 델프트 33%. 경로 길이별 20%(10km), 60%(21km), 87%(42km). 저자는 8km 이하 짧은 경로는 인식이 자주 실패한다고 적었다.
- 한계(저자): 분류기가 여러 획의 낙서로 학습되어 한 획 GPS 아트와 도메인이 다르다. 템플릿 매칭은 강체이며 최적 해 보장 없음.
- 우리에게 주는 의미: **우리의 3~8km 제약이 인식에 불리한 구간일 가능성**을 시사한다. 단, 다른 모양과 다른 분류기를 쓴 결과라 우리 수치로 옮길 수 없다.
- 읽은 범위: 본문 약 120,000자 중 앞 100,000자와 별도 발표 자료. 결론 부분은 읽지 못했다.

### 2-2. Li & Fu (2026, ISPRS IJGI): 불변 관계 기반 도로 부분그래프 검색
- 방법: 입력 모양을 회전·크기·이동에 불변인 **꺾임각과 길이비**로 기술해 그래프로 만들고, 도로망을 동적 그래프로 보며 역추적 부분그래프 매칭으로 허용 오차 안의 도로 경로를 **모두** 찾는다. 결과는 위치 편차와 간격으로 순위를 매긴다.
- 성능(저자 보고): 5개 도시 10km×10km 영역에서 단일 도형 검색 2초 이내. 조합 도형 "1314"는 최대 약 1,726초.
- 평가: 사람 인식 평가 없음. 시각 순위 확인뿐.
- 한계(저자): 한자·십이지 같은 복잡한 도형에서 어려움. 의미 기반 검색을 향후 과제로 제시.
- 우리에게 주는 의미: Codex가 쓴 빔·롤아웃 방식과 **다른 계열**의 탐색이다. 템플릿 라이브러리와 결합하면 "이 동네에서 템플릿 N개가 어디에 몇 번 나타나는가"를 열거하는 발견형 탐색이 된다. 우리 파이프라인의 폐곡선·3~8km·반복률 제약과의 호환은 미확인이다.

### 2-3. Diamonds in the Sky: 구름 속 동물 (Horovicz 외, arXiv 2026-05-31)
- 방법: SAM으로 구름 조각 분할 → 9종 동물로 확산 모델(MDDS) 변형 → OneFormer가 동물을 인식하고 마스크 IoU≥0.5, SSIM≥0.7이면 채택 → 원본과 보간하는 영상으로 "보이도록 돕기".
- 사람 평가: 50장·250조각, 304 응답, **고정 9종 목록에서 선택(자유 명명 아님)**. 전후 비교.
- 결과: 도움 전 정밀도/재현율 0.11/0.28, 도움 후 0.30/0.55(F1 0.16→0.39). 무작위 0.06/0.07, 설문으로 정한 상한 참조 0.42/0.48. **CLIP과 OneFormer는 원본 조각에서 동물을 하나도 검출하지 못했다.**
- 한계(저자 요약 기준): 확산 결과 중 인식된 것은 12%, 이 중 약 22%만 검증 통과. 동물 9종 제한. 전후 고정 순서 설계라 반복 노출 효과가 섞일 수 있고 통제 조건이 없다.
- 우리에게 주는 의미: (a) **참고 그림/도움 그림이 사람의 인식을 높인다는 선행 근거**로, road-first 참고 그림 기능의 방향을 지지한다. (b) 고정 목록 선택 + 무작위 기준선이라는 평가 틀을 그대로 쓸 수 있다. (c) 자동 인식기가 사람이 보는 모양을 못 잡는 현상이 구름에서도 나타났다.
- 읽은 범위: arXiv 직접 접속이 허용되지 않아 alphaxiv의 요약 페이지로 읽었다. 숫자는 그 페이지 기준이다.

### 2-4. BareBones (2026): 실루엣만 주었을 때 VLM의 형태 이해
- 6개 데이터셋, 26개 모델. 텍스처를 없애면 평균 정확도 34.7%→21.0%. 포켓몬 실루엣(WTP-Bench)에서 Claude Sonnet 4.5 53.10%, GPT-4.1 49.48%, Gemini 2.5 Pro 23.02%, 오픈 가중치 모델 대부분 2.2% 미만. 새 CUB-200은 137종이 모든 모델에서 0%.
- 한계(저자): 해상도 200px, 이진화 영향 미검증.
- 우리에게 주는 의미: **형태만 보고 이름을 맞히는 능력은 최신 상용 VLM에서만 일부 가능**하고, 알려진 클래스가 적을수록 쉽다. 우리 자동 판정을 오픈 모델(소형 CLIP류)로 하면 바닥에 붙을 가능성이 크다. 이 벤치마크는 **채운 실루엣**이다. 우리 앱은 외곽선 선 그림으로 렌더링하므로, **채운 실루엣 렌더링이 더 인식되는지**는 값싸게 시험할 가설이다(미검증).

### 2-5. 사람 인식의 기준선
- Eitz 외(2012, TU-Berlin): 250개 범주 2만 장 스케치를 사람이 맞힌 비율 73%, 컴퓨터 56%(우연 0.4%). 페이지에 맞힘 방식(선택지 수)은 적혀 있지 않았다.
- 의미: 의도적으로 그린 스케치도 사람 인식률이 73%에 그친다. 도로 고리에 80% 같은 인식률을 목표로 삼는 것은 비현실적일 수 있으므로, 기준은 "무작위 대비 상승분"이 더 방어 가능하다.

## 3. 응용 아이디어 (모두 미검증 제안)

**A. 실루엣 라이브러리 검색으로 이름 붙이기.** 앱이 이미 만드는 자연 고리(블록 합집합)를 **채운 실루엣**으로 렌더링하고 MPEG-7·QuickDraw 예시와 형태 기술자 또는 임베딩으로 가장 가까운 예시를 찾는다. 새 사람 평가 데이터 없이 시작할 수 있다. 도메인 차이(도로 고리는 직교 다각형)가 크다는 위험이 있다.

**B. 불변 부분그래프 검색으로 템플릿 열거.** Li & Fu 방식으로 템플릿 라이브러리 각각이 이 동네에 몇 번 나타나는지 열거한다. 우리 제약(폐곡선, 3~8km, 반복률)과의 호환을 먼저 확인해야 한다.

**C. 참고 그림의 효과 검증.** Diamonds in the Sky의 고정 목록 선택 + 무작위 기준선 틀로 "도로만" vs "도로 + 참고 그림"을 비교한다. 외부 AI 키 없이도 진행할 수 있다.

**D. 길이 구간 민감도.** Delft 결과가 우리에게도 해당하는지, 이미 가진 후보(3~8km) 안에서 길이별로 인식이 다른지만 먼저 본다. 새 생성은 필요 없다.

**E. 판정기 선택.** 자동 판정은 채운 실루엣을 주고 상용 최신 VLM으로 하는 것이 BareBones 근거상 그나마 합리적이다. 어떤 경우에도 사람 인식률로 보고하지 않는다.

## 4. 한계와 주의
- 요약 도구로 읽었으며 논문 본문 전체를 확인하지 않았다. 숫자는 인용 시 원문을 다시 확인해야 한다.
- arXiv 직접 접속이 막혀 Diamonds in the Sky는 요약 페이지로만 읽었다.
- 위 연구들은 모두 도로 고리 + 사람 자유 명명을 직접 측정하지 않았다. 우리 문제의 성능으로 옮길 수 없다.
- 이 조사는 "어떤 기술을 응용할 수 있나"에 답할 뿐, 어느 것이 실제로 효과적인지는 시험하지 않았다.
