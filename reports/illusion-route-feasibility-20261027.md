# 착시 원리를 이용한 실제 경로 추천 실험

2026-10-27. 사용자는 완성 경로를 풍경으로 꾸미는 것이 아니라, 멀리서도 사물처럼 보이는 실제 도로 경로를 찾는 용도를 선택했다.

## 모델 조사와 적용 범위

[QR Code Monster 모델 카드](https://huggingface.co/monster-labs/control_v1p_sd15_qrcode_monster)는 QR 조건 그림으로 창의적인 이미지를 생성하는 ControlNet 모델을 설명한다. [IllusionDiffusion 공개 구현](https://huggingface.co/spaces/AP123/IllusionDiffusion/blob/main/app.py)은 해당 ControlNet과 Realistic Vision, Stable Diffusion 파이프라인을 사용한다. 이 입력과 출력은 픽셀 이미지이며 실제 도로 간선의 연결이나 거리 제한을 보장하지 않는다.

따라서 이번 적용은 생성 모델 설치가 아니라 **착시 원리에서 착안한 다중 해상도·흐림 평가 시제품**이다. 기존 유효 도로 후보의 순위를 바꾸는 데 사용할 수 있는지 먼저 진단한다. Gaussian blur 및 픽셀 비교는 학습 모델이 아니다. ControlNet 가중치를 내려받거나 추론을 실행하지 않았으며 앱 기본 경로 생성기도 바꾸지 않는다.

## 실행 전 가설과 조건

가설: 사소한 꺾임이 약해진 여러 해상도에서도 기준 윤곽을 보존하는 경로가 원본에서도 사물로 잘 읽힐 수 있다. 이 가설은 평가 결과를 통해 확인해야 하며, 흐림 점수 자체가 인식률은 아니다.

- 고정 자료: semantic-feature-20261025의 6조건×3방식 출력18개. 새 경로 생성이나 독립18표본으로 부르지 않는다.
- 원본 그림과 경로를 같은 배치·같은 뷰포트에 그린다. 후보마다 독립 정규화하여 상대 위치나 비율 오차를 지우지 않는다.
- 400px 캔버스에서 흐림 sigma0/2/4/8을 고정하고 평균을 후보 선택 대리 지표로 사용한다. 64px 축소는 별도 표시 진단이다.
- 흰 배경 일치가 점수를 지배하지 않도록 전경 선의 정규화 내적을 사용한다. 빈 그림의 점수는0이다.
- 빈 그림·원·네모·고정 난수 선을 부정 대조로 기록한다. 일반 도형이 실제 후보보다 높으면 의미 특이성이 부족하다는 증거로 남긴다.
- 본 실험에서는 물리 도로가 바뀌지 않는다. 최종 성공은 선택한 원본 경로의 이름 없는 인식 개선으로 검증해야 한다.

## 협업 검토

비판적 검토자는 흐림으로 배경이 비슷해지는 현상과 사물 인식을 혼동하지 말라고 지적했다. 비전문가 관점 AI는 작은 선명한 화면을 기본 진단으로 두고, 흐림으로 선이 사라지거나 합쳐져 원래 없는 형태가 생기는지 확인하자고 제안했다. 두 역할은 별도 에이전트이며 사람 실험이 아니다.

직전 특징 가중 실험은 도로 검증24상태를 통과했지만 독립 의미 평가 에이전트가 사용량 제한으로 중단되어 명확 인식 판정은 미완료다. 이번 자료를 인식이 이미 개선된 경로라고 전제하지 않는다.

## 단독 후속 조사: 모델별 역할

사용자가 협업 지시를 취소한 뒤 이번 후속 작업은 하위 에이전트 없이 수행했다. 범위 제한을 두라는 요청은 아니며, 아래 결론은 기술 적합성과 실측에 따른 판단이다.

| 후보 | 공개 구현의 역할 | 도로 추천 적용 판단 |
|---|---|---|
| QR Code Monster / IllusionDiffusion | 조건 이미지의 패턴을 장면 속 명암으로 표현 | 경로를 풍경으로 꾸미는 용도에는 맞지만 도로 생성기로 직접 교체할 근거 없음 |
| Factorized Diffusion | 이미지의 저주파·고주파 성분을 서로 다른 프롬프트로 조건화 | 멀리서 읽히는 큰 형태를 제안하는 연구 후보. 실제 도로 투영은 별도로 필요 |
| Visual Anagrams | 회전 등 여러 변환에서 다른 이미지로 보이도록 생성 | 같은 사물이 안정적으로 읽혀야 하는 현 목표에는 우선순위 낮음 |

근거: [Factorized Diffusion 저자 구현](https://github.com/dangeng/visual_anagrams/blob/main/readme_factorized_diffusion.md), [Visual Anagrams 저자 저장소](https://github.com/dangeng/visual_anagrams), 앞의 IllusionDiffusion 공개 코드. 적합성 판단은 이 기능 설명에 기반한 본 프로젝트의 추론이며 도로 생성 성능이 논문에서 검증됐다는 뜻이 아니다.

## 현재 환경 확인

기존 eval/recognition/model-env의 Python으로 확인했다. torch2.14.1+cpu, CUDA 사용 가능 여부 false, transformers/PIL 설치됨, diffusers 미설치다. NVIDIA 관리 명령은 PATH에서 찾지 못했고 장치 정보 조회는 접근 제한으로 실패했다. 따라서 물리 GPU가 없다고 단정하지 않는다. 기본 Hugging Face 캐시에서 확인한 CLIP·QR Code Monster·DeepFloyd IF-I-XL의 주요 설정/가중치 파일은 발견되지 않았다. 다른 경로의 캐시 전체를 검색했다는 의미는 아니다.

모델 추론은 아직 실행하지 않았다. CPU만 연결된 현재 환경에서 대형 확산 모델을 즉시 서비스에 적용할 수 있다고 보고하지 않는다. GPU 실행 환경과 해당 모델의 가중치·의존성을 준비한 뒤 검증해야 한다.

## 실측: 흐림 점수 상승은 시인성 개선을 뜻하지 않음

고정18출력에서 sigma0/2/4/8을 비교했다. 평균 다중 흐림 선택은 기존 기하학 순위와3/6, sigma0 코사인 순위와2/6 달랐다. 다중 흐림 선택의 기하학 평균65.0435, 기하학 선택73.0533이며 같은6조건에서의 재정렬 결과다.

후속 신호 감사(`scripts/recognition-lab/illusion-signal-audit.mjs`)는 입력/그림 해시를 확인하고72개 PNG의 실제 회색 픽셀을 읽었다.

- sigma8의 코사인 점수는18/18에서 sigma0보다 높아졌다.
- 검은 선의 총량(픽셀 밝기 감소량 합)은 평균98.47% 남았지만, 대비 에너지(밝기 감소량 제곱합)는 평균14.51%만 남았다.
- sigma8의 이미지별 최대 대비 평균은24.01%였다. 대비50% 이상인 픽셀은 모든 이미지에서0개였다. 이는 정해진 픽셀 측정이며 사람에게 안 보인다는 임계값 판정은 아니다.
- sigma2/4/8의 최고 후보 선택은 동일했다. 단순히 더 흐리게 하는 것으로 추가 후보 개선이 나타나지 않았다.
- 고정된 부정 대조가 각 수준 최고 실제 후보를 넘은 조건은0/6이었다. 제한된 대조군 결과이며 사물 의미가 검증된 것은 아니다.

따라서 다중 흐림 대리 점수만으로 추천 모델을 교체하지 않는다. 원본 인식 성과는 미측정 상태다. 결과는 `illusion-route-20261027/signal-audit.json`, 시각 비교는 `../public/eval/multiscale-route-20261027.html`에 있다.

## 실제 모델을 연결할 설계와 통과 조건

적용 가능성은 **형태 제안 모델 + 실제 도로 제한 탐색 + 원본 검증**으로 좁힌다. 아직 구현/추론 완료를 뜻하지 않는다.

1. Factorized Diffusion 계열로 사물의 저주파 형태 후보를 제안한다. 기존26종 기준 그림은 비교군으로 보존한다. 생성 장면의 색·질감·채색은 추천 경로로 간주하지 않는다.
2. 형태 후보를 여러 단순 선 표현으로 바꾸고, 기존 도로 그래프에서만 연결 경로를 탐색한다. 생성 픽셀이나 가까운 도로 사이에 가짜 연결을 추가하지 않는다. 끊김·길이·반복·영역 실패는 탈락으로 기록한다.
3. 변환 전 생성 이미지, 도로 변환 후 원본 선, 축소된 원본 선을 구분해 평가한다. 생성 이미지에서만 인식되고 실제 경로에서 사라지면 전이 실패다.
4. 동일 지역·후보 수·계산 예산에서 기존 기준 그림 방식과 비교한다. 모델 선택에 쓴 판정을 최종 인식 정확도로 재사용하지 않는다. 단독 AI 검토는 개발 진단이며 독립 사람 검증을 대체하지 않는다.
5. 핵심 통과 기준은 원본 실제 경로의 명확한 자유 인식 증가와 검색 요청 성공률 증가다. 모델 confidence·흐림 코사인·기하학80을 대체 성공 기준으로 쓰지 않는다.

바로 가능한 것은 실험 평가·GPU 환경 준비·형태→도로 변환 연구다. 원클릭으로 착시 생성기를 붙여 실제 경로 추천이 좋아진다는 결론은 현재 자료로 지지되지 않는다.
