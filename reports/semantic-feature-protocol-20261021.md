# 식별 특징 우선 생성: 실행 전 기준

2026-10-21. 최우선 목표는 설명 없이 사물로 인식되는 실제 경로 추출이다.

## 가설과 비교

H1: 고정 그림의 식별 특징에 해당하는 윤곽 구간을 우선 보존하면 전체 기하학 오차만 줄이는 방식보다 원본 자유 인식이 개선된다. 수작업으로 지정한 특징은 가설이며 학습된 부위 검출이나 실제 의미 인증이 아니다.

첫 실험은 기존 trial-v1의 초기 6경로와 초기 배치를 고정한다. 개발 자료 재사용이며 새 지역 검증이 아니다. 각 조건에서 기존 기하학 수선, 균일 특징 가중 대조, 식별 특징 가중 수선을 비교한다. 제안 상한192, 제안당 확장 상한12,000을 동일하게 둔다. 실제 연산 횟수와 시간을 별도로 보고한다. 최초 가설은 고정 배치에서의 특징 가중 국소 수선에 한정되며 도로망 전체의 특징 우선 발견을 구현했다는 뜻이 아니다.

특징 구간·가중치·수용 목적함수는 출력 관찰 전에 구현 프로토콜에 저장한다. 기하학 점수가 내려가더라도 특징 목적함수를 개선할 수 있도록 하되 원래 점수는 수정하지 않고 그대로 보고한다. 유효성은 실제 연결 도로·폐곡선·영역·원본/투영 길이3–8km·반복률0.2 이하로 유지한다. 실패는 분모6에 남긴다.

## 의미 판정

방법·대상명·점수·참고 그림을 숨긴 개별 이미지를 같은 크기, 같은 선 굵기, 북쪽 위로 제공한다. 하나씩 자유 명명한 후 명확/약한 연상/없음, 실제로 보이는 근거를 기록한다. 정답을 알아야 할 수 있는 회전이나 꾸밈은 사용하지 않는다. 평가자는 실제 사람이 아닌 별도 AI임을 기록한다. 유사한 후보를 여러 장 보는 데 따른 연상 가능성은 남는다.

명확 인식은 '하나의 사물/동물 해석이 주도하며 실제 선의 구체적 특징으로 설명됨'으로 정의한다. 도형명·지역 경계·막연한 덩어리와 설명이 있어야 성립하는 해석은 성공으로 세지 않는다. 목표와 다른 사물을 명확히 알아본 경우 자유 인식 성공과 목표 일치를 따로 집계한다. 현재 작은 표본은 탐색 진단이며 통계적 우위를 입증하지 않는다.

## 사전 결정 규칙

- 가중 방식의 명확 인식 수가 두 대조군보다 늘어야 H1의 후속 검증 근거로 삼는다. 증가가 없으면 이번 구현·자료에서 지지하지 않는다.
- 기하학·특징 점수만 좋아진 것은 의미 성과가 아니다. 목표에 맞는 이름을 강제로 붙이지 않는다.
- 1~2개 개선만 있어도 새 지역 재검증 전에는 앱 기본을 변경하지 않는다.
- 두 필수 역할: 비판적 검토자와 비전문가 관점 검토자. 후자는 이전 정답 대화를 상속하지 않은 에이전트지만 AI 평가다.
- holdout-v2, 원래 고정12, fit.ts 및 shapes.ts를 변경하지 않는다. 외부 유료 API 호출은 이번 회차에 사용하지 않는다.

실행 결과 및 반증은 별도 결과 보고서에 남긴다. 결과를 본 뒤 이 기준을 성공에 맞춰 수정하지 않는다.
