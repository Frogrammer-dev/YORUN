# 실제 도로 선분을 따라 진행하는 대응 설계 근거

2026-10-13. 원래 평가식과 실제 도로 조건은 유지한다. 아직 실제12조건의 새 품질 결과가 아니다.

## 확인한 문제

같은3.2km 네모가 native100점이어도800m 간선 네 개 표현은 rollout에서 탈락하고100m로 나눈 표현은 통과했다. 실제 도로 노드 끝점만 보고 guide 전진을 판단하는 방식은 길 위 점의 간격에 의존한다. 실제 광안리 자동 배치에서도 강제 진행 직후 이전 단계에서는 가능하던 간선을 배제한 국소 사례51개가 있었다. 알려진 좋은 배치에서는 같은 국소 사례0개였으므로 전체 실패의 단독 원인이라는 결론은 내리지 않는다.

## 일차 자료와 적용 범위

Alt·Efrat·Rote·Wenk의 [Matching planar maps, 2003](https://page.mi.fu-berlin.de/rote/Papers/pdf/matching-planar-maps.pdf)는 그림 곡선과 도로 그래프를 연속적으로 대응시키는 문제를 다룬다. 선분 내부의 가능한 대응 구간과 양쪽 진행 순서의 보존이 핵심이다. 이 자료는 선분 단위 대응 설계의 근거이며 우리 평균 점수식, 폐곡선,3–8km·반복0.2 조건을 해결하거나80점을 보장하는 자료가 아니다.

## 먼저 구현한 구성 요소

`segmentRadiusInterval.ts`는 실제 선분의 매개변수t∈[0,1] 중 checkpoint와 반경 안에서 대응할 수 있는 전체 구간을 계산한다. 실제 경로 점은 만들지 않는다. 가장 가까운 투영점 하나만 선택하면 가능한 순서 대응을 놓칠 수 있다. 예를 들어0→10 선분에서 checkpoint8과7을 반경3으로 맞추면 최근접 투영은0.8→0.7로 뒤로 가지만, 허용 구간[0.5,1]과[0.4,1]은0.5→0.5라는 순서 대응을 허용한다.

계약3개로 이 사례, 역방향·접선 접촉·끝점 clipping·길이0, 같은 선분 분할 후 허용 위치 보존을 확인했다. 이는 보조 함수의 정확성이지 전체 Fréchet 알고리즘 구현 또는 품질 증명이 아니다. 후속 DP의 endpoint phase 대안4개 제한도 미래 최적해 보존의 증명이 아닌 검색 상한으로 기록한다.

## 후속 검증

원래 sparse/dense 네모에서 둘 다 실제100점 폐곡선을 얻어야 한다. 실제 반환 배열은 입력 그래프의 기존 노드와 간선만 포함해야 한다. native 길이·반복률·원래 영역을 재검증한다. 검색 대응의 내부 위치와 반환 경로를 혼동하지 않는다. 이 gate를 통과한 후 자동 배치·고정 원자료·원식으로 Control/Feedback을 비교하고, 검색 분기 수·DP 계산량·실제 Q와 보정 호출 수를 별도로 기록한다.
