# 서면 네모의 실제 교차점 연결 품질 진단

이 실험은 기존 자동 탐색이 만든 서면 네모를 진단 대상으로 삼은 positive control이다. 수동으로 선정한 경로 교체이므로 자동 알고리즘의 개선으로 계산하지 않는다. 공유 알고리즘과 평가식은 수정하지 않았다.

원래 경로의 82.619m 연결 구간을 인접한 실제 직선 도로들의 공통 노드 262를 통과하도록 바꿨다. 양쪽 도로를 59.735m와 50.822m 연장하므로 전체 경로는 3185.865m에서 3213.803m로 늘어난다. 모든 점과 연결은 기존 고정 도로 그래프에 존재한다. 닫힌 경로, 원래 영역, 3–8km, 반복 비율 0 조건을 통과했다.

| 원식 지표 | 원래 경로 | 실제 교차점으로 교체 |
|---|---:|---:|
| 반올림 전 유사도 | 84.846212 | 84.665216 |
| 표시 유사도 | 85 | 85 |
| 평균 편차 | 8.838360 | 8.977677 |
| km당 꺾임 지표 | 0.627773 | 0.622316 |
| 실제 길이(m) | 3185.865175 | 3213.802775 |

원래 순서와 기하학 기준 정규화 순서를 각각 평가했다. 양쪽 경로 모두 순서별 점수 차이가 없다. 같은 초기 배치에서 양쪽 각각 원래 순서 고정, 정규화 순서 고정, 매 배치마다 정규화하는 세 종류의 균일 배치 최적화를 시행했다. 각각 최대 128회, 이동 ±0.2배 크기, 크기 0.8–1.2배, 회전 ±30°의 동일 제약을 사용했다. 실제 탐색은 41회에서 개선 없음으로 종료됐으며 점수는 그대로였다. 기존 경로의 가장 강한 대조군보다 교체 경로가 0.180996점 낮다.

연결을 곧게 정리해 꺾임이 조금 감소했지만, 원래 네모 템플릿에서의 평균 편차 증가가 더 컸다. 따라서 이 한 구간을 공통 교차점으로 교체하는 것을 개선안으로 채택할 근거는 없다. 이것은 다른 경로의 교차점 교체 가능성을 부정하거나, 네 구간 표현으로 모든 좋은 경로를 만들 수 있음을 뜻하지 않는다. 여러 실제 도로 구간으로 구성된 기존 85점 경로를 그대로 보존해야 한다.

재현: 환경 변수 `CORNER_QUALITY_AUDIT=1`로 `tests/eval/corner-quality-audit-20261013.test.ts` 실행. 데이터는 `eval/recognition/route-improvement/corner-quality-audit-20261013/results.json`에 있다. 도로 및 두 입력 결과 파일의 SHA-256, 8개 코드 원본과 저장 사본의 바이트 SHA-256을 확인했다. Vitest 1개 통과, 해당 테스트 ESLint 통과. 새 지역 holdout은 읽지 않았다.
