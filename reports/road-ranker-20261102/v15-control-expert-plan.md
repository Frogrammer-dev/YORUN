# v15 양성·음성 대조 전문가 계획

2026-11-03. 현재 저장 자료를 읽은 비판적 설계 제안이다. 새 실험·렌더링·모델 실행은 하지 않았다. 이 문서만 추가하며, 아래 수치는 main이 실행 전에 프로토콜로 확정할 제안이다. 기존75요청 기준·평가 정의·모델 임계값은 변경하지 않는다.

## 출발 근거와 진단 목적

`v14-results.md`의 최종 결과는 A clearTarget3/75, B2/75, 동물 양쪽0/33, primary 양쪽0이다. B의 두 명확 사례는 바지·망치의 미지원 A fallback으로 새 특징 생성 성과가 아니다. 앞서 보존한 `v14-expert-audit.json`은 실제도로·좌표·구조 조건을 감사한 기록이며 의미 인식 증거가 아니다. 기술 기준도 유효 요청62→56의 손실6으로 실패했다. 특징 충족5→17만으로 H14를 채택하지 않는다.

아직 빠진 대조는 **도로 변환 전 목표 외곽 자체가 같은 평가 절차에서 읽히는가**다. 이상적 외곽도 안 읽히면 추가 경계 제약만으로 회복하기 어렵다. 그러나 대조 실패만으로 AI가 너무 엄격하다고 결론 낼 수도 없다. 외곽 표현·렌더링·게임 범주·평가 규칙·평가자 민감도를 분리해 의심해야 한다. v15는 이 진단이며 도로 성과나 인간 인식률을 측정하지 않는다.

실제 읽은 계약: `protocol-v12.md`, `v12-dataset/dataset.json`의 classes/records, `features-metadata.json`, `diversityCatalog.ts`, 원본 shapes/objectTemplates 및 v14 결과. 데이터에는 id/classIndex/className/groupSHA256/split/strokes/sourceRecognized가 있다. 실제 범주는24대상+8generic32종이며 rocket은 없고, 일반 경쟁 범주는 square/circle/triangle/hexagon/octagon/line/zigzag/map이다. sourceRecognized=true는 Quick Draw 게임 모델 판정이며 사람이 해당 그림을 알아봤다는 보증이 아니다. CLIP 특징은 이 대조에 필요 없다.

## 고정 표본·분모

1. **T: 원본 템플릿25장.** 현재 catalog가 참조하는 외곽을 수정 없이 사용한다. 로켓 포함25/25와 동물11/11·사물14/14를 유지한다. 특징 모듈18지원/7미지원 여부는 T 표본 제외 기준이 아니다.
2. **H: 대상 손그림48장.** v12의24지원 범주에서 기존 `split=test`만 대상으로 범주당2개. 클래스별 `(SHA256('v15-control-v1|' + groupSHA256 + '|' + id), id)` 오름차순 최초2개를 선택하고 ID·groupSHA·원본 파일 해시를 먼저 동결한다. 미리 보기·모델 score·v12 test 오답 여부로 고르지 않는다. 서로 다른 groupSHA를 요구하며 부족하면 결측으로 남기고 train/val이나 다른 종으로 대체하지 않는다. 로켓은 자료 없음으로 H에서 별도 NA이며 T25에서 삭제하지 않는다.
3. **G: generic8범주, 범주당2개=16장 권고.** 같은 기존 test·선택 규칙을 쓴다. 따라서 제안 전체89장=T25+H48+G16이다. 'generic8'을 총8장으로 쓸 경우81장이므로 main은 실행 전에 둘 중 하나를 명시해야 한다. 이 문서의 비율·제안 판정은16장 기준이며 결과 후 바꾸지 않는다.

T와 H의 같은범주 직접 비교는 로켓을 제외한24종에 한정하여 T24 대 H48의 **범주 평균**을 사용한다. T25 전체 결과도 따로 보존한다. H 동물22·사물26, G16의 결측까지 예정 분모에 남긴다. 두 그림만으로 한 범주의 본질적 난도를 추정하거나 2개 중 나은 것만 집계하지 않는다. 그림별·종별·평가자별 수와 분모를 모두 제공한다.

기존 test는 모델 선택에 쓰지 않았더라도 v12 성능 집계에 이미 사용됐다. 따라서 'v12 train/val과 분리된 기존 test의 고정 진단 표본'이라고 부른다. 새 독립 test라고 하지 않는다. 이번 자유 명명 피드백을 후속 템플릿/선택기 개발에 쓰면 이48개·16개와 해당 평가는 개발 자료가 되며 다음 성능 검증에는 새 독립 자료가 필요하다.

## 렌더링·사전 노출 통제

- T/H/G 모두 동일 캔버스·여백·검은 선·선 굵기·배경·bbox 균일 정규화·y축 규칙으로 렌더링한다. T는 원본 정방향, H/G는 수집된 정방향 한 view만 쓴다. 회전 최대값 선택이나 '알아보기 쉬운' 재배치는 금지한다. 원본 개별 획은 유지하고, 손그림의 떨어진 획을 연결하거나 열린 획을 닫지 않는다. T의 폐곡선 대 H의 다중획/내부선 차이는 제거할 잡음이 아니라 **표현 차이라는 진단 대상**이다. 동일 렌더러가 동일 정보량을 뜻하지 않는다.
- 방법·파일명·클래스명·선택된25종 목록·참고 그림·도로 실패 정보는 평가자 입력에 넣지 않는다. 무작위 중립 토큰·순서를 해시 고정하고 T/H/G를 섞는다. 같은 범주를 연속 배치하거나 T-H를 나란히 보여주지 않는다. 자유 명명 먼저, 이어 clear/weak/none과 실제 보이는 선 근거를 받는다. 동의어와 종/상위범주 판정은 먼저 동결하며 사후에 답에 맞춰 넓히지 않는다.
- 공개 mapping·HTML title·이미지 경로·alt·요청 본문에도 이름이 새지 않게 한다. 새로운 평가 세션에는 기존 사례 이름·v14 판정·이번 가설을 넘기지 않는다. 완전한 미노출은 보장할 수 없다. 기존 템플릿은 프로젝트에서 반복 노출됐고 같은 계열AI의 학습 사전지식도 제거할 수 없다. '새 문맥의 익명 평가'와 '처음 보는 모델/사람'은 구별한다.
- 같은 pixel은 여러 표본/방법에 나타나도 독립 증거로 중복 계산하지 않는다. 토큰 제외 본문 pixel hash, mapping/manifest/원본 해시와 bridge 정책을 보존한다. 과거 판정과 충돌하면 성공 쪽만 택하지 말고 충돌 및 재평가 규칙을 먼저 정한다. 이미 알려진 그림을 다시 평가한 것은 새 일반화 증거가 아니다.
- mug↔coffee_cup, bottle↔wine_bottle, turtle↔sea_turtle의 범위 차이를 숨기지 않는다. 거북이류 일반 자유 명명과 바다거북 좁은 범주 일치는 따로 기록한다. 손그림 source label은 수집 의도이며 자유 이름의 사람 정답이 아니다.

## 무엇을 긍정 대조 통과로 볼 것인가

기존 primary를 primary로 유지하고 각3AI 원본·보조 다수결을 함께 보고한다. v14에서 엄격했다는 이유로 primary를 교체하지 않는다. 자유 사물 인식과 수집/생성 의도 일치 clearTarget은 별도 집계한다. 예를 들어 고래를 물고기로 읽은 경우 broad animal 연상과 종 일치를 구별한다.

실행 전 진단 기준 제안: primary의 H target-clear≥36/48, 동물 H≥16/22를 '평가 절차가 이 고정 손그림에서 충분히 작동'하는 조건으로 두고, T target-clear≥18/25·동물 T≥8/11을 '이상적 외곽 표현의 작동' 조건으로 둔다. G에서 구체적 비generic 사물/동물로 clear 오명명≤2/16을 별도 보수성 점검으로 둔다. 이는 모델 FAR/학습 gate가 아니고 소표본의 운영상 진단선이며 신뢰구간·원시 건수를 함께 본다. G도 map처럼 사람이 사물로 읽을 수 있으므로 수집 label을 절대 negative 정답으로 간주하지 않는다. 기준 초과는 오인식 위험 신호이지 곧 평가자 오류 확정이 아니다.

숫자를 하나로 합쳐 T와 H의 성공률을 주장하지 않는다. 특히 89장 성공을75개 도로 요청 성과로 바꾸지 않는다. 특정종2개만의 불일치는 표본 한계로 표시한다. 양성 대조를 통과하도록 평가 문구·clear 정의·margin·lambda·표본을 바꾸지 않는다.

도로 anchor 표시는 이번 최소 대조에서는 빼는 편이 낫다. 추가한다면 T/H와 분리된 사전 고정 부진단으로, 같은 템플릿의 실제 snap pins/원래 canonical view를 쓰고 이름·연결선을 추가하지 않는다. anchor 점이나 직선 연결은 실제 유효 도로 경로가 아니며 인식 성공으로 집계하지 않는다. 새 geometry 탐색은 이 진단에 포함하지 않는다.
