# v12 동물 포함 학습 모델: 손그림 개선, 실제 도로 선택 실패

동물11종을 포함한 모델을 실제로 학습하고, 기존 도로1003개를 그대로 사용해25종×3지역75조건에서 비교했다. **손그림 보조 기준은 통과했지만 도로 명확 판정은 기존8/75에서4/75로 감소했다. 이번 모델을 개선 완료로 채택하지 않는다. 사람 인식은 미측정이다.**

## 검토 화면과 모델

- [새 모델의 이름 없는 사람 검토 화면](../../public/eval/route-study-20261102-a/blind.html) — 17개 추천만 표시하며58개 보류도 전체75분모에 포함한다. 이름을 보기 전에 사용한다.
- [25종별 비교·보류·GPX](../../public/eval/route-study-20261102-a/index.html) — 참고 외곽과 이름이 있는 진단 화면이다.
- [비교 모델의 이름 없는 화면](../../public/eval/route-study-20261102-b/blind.html) — 7개 추천,68개 보류.
- 학습 체크포인트: `eval/recognition/road-ranker-20261102/v12-dataset/sketch-models.npz`. 알고리즘 구현은 sketch-head.py,75요청 선택은 diversity-select.py. 앱 기본은 교체하지 않았다.

사전 기준은 >=13/75, 동물3종·사물3종이 각각2지역 이상 명확, 도로유효100%, 보류분모 유지였다. 명확 판정 전부터 head의 동물 추천은 기린2지역·물고기1지역뿐이어서 다양성 기준이 불가능했으며 실제 명확 판정도 기준 미달이다.

## 학습 자료와 보조 성적

추천24범주(동물11·사물13)+일반경쟁8범주, 총2304그림, train1646/val316/test342. 기존1368개의 원본·분할은 정확히 보존했다. 동일 원본의 회전·획역방향·획순서 변형을 그룹화하며 도로AI 판정은 학습에 쓰지 않았다. 공식 자료에 rocket이 없어25범주 전체 학습 수집은 실패했고 로켓3조건을 미지원 보류로 유지했다. turtle은 sea_turtle, mug는 coffee_cup 자료다.

사전 손그림 보조 기준은 통과했다. 그러나 개 test3/9,새4/8처럼 약한 범주와 작은 분모가 있다. 범주가 다른 v10의93.19%와 직접 우열 비교하지 않는다. recognized는 원래 게임 모델 판정이며 사람이 도로를 알아본 정답이 아니다.

## 반증과 다음 판단

이번 실험은 분류기만 확장하면 도로 선택이 개선된다는 가설을 지지하지 않는다. 다만 원인은 분리해야 한다. 원래AI 명확했던 전주 오리의 분류는 티셔츠여서 보류됐고, 같은 원본 경로를 선택한 천안·전주 바지는 표시각이 각각180도·270도 달라졌다. 따라서 분류·후보 선택·표시 방향이 함께 바뀐 전체 방법의 실패이며, 이를 전부 도로 생성 탓으로 단정하지 않는다. 방향만 고정한 대조가 진단에 필요하다.

동시에 방향을 바꿔도 동물 추천 범주 부족 때문에 사전 다양성 기준은 통과할 수 없다. 다음 실험은 단순 임계값 재조정보다 도로 후보에 식별 특징이 남는지 검사해야 한다. 과거 parts/motif/semantic-feature 실패를 먼저 검토하고 새 가설과 기준을 고정한다. 원래12조건·점수식·holdout-v2는 보존한다.

## 무결성·평가 한계

1003개 원본행과 생성 counts는 두 방법 모두 정확히 보존했다.17+7개 GPX 좌표를 원본과 대조했고 표시 회전은 실제 좌표를 바꾸지 않는다. 전체 source의 도로 유효성은 v11 실제 간선 감사로 연결된다.

동일 RGB 도로 본문 픽셀만 기존 판정에 연결했다. 신규20개 고유 이미지로3AI 자유 명명했으며 각 방법/평가자별2개 이전 판정을 재사용했다. 새 이미지의 경로·토큰은 방법과 정답을 드러내지 않는다. bridge 내용 fingerprint,PNG 해시,토큰 순서·중복을 검사하고, 이전 동일 픽셀의 답이 충돌하면 새 평가로 보낸다. 재사용을 독립 신규 성공으로 세지 않는다. 응답의 자기표시 Codex와 실제 도구 agent ID를 모두 보존했다.

3AI는 같은 계열로 상관될 수 있고, 모두 이미 개발에 사용한3지역이다. 사람 평가·독립 새 지역 검증·범용 성능은 미완료다. 실제 사람 답변은 아직 없다.

Python54개 검사와 새 bridge 무결성 회귀 검사 통과. 두 검토 화면의25종 필터,빈 답변,평가자 변경 초기화,저장 차단 상황의 답변 내려받기도 확인했다. 원본 실행·집계는 v12-*-audit.json,sketch-head-v12-*.json,diversity-v12-*-ai-results.json,ai-review-v12-*.json 및 protocol-v12.md를 따른다.
