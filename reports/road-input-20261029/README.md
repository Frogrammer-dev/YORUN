# 실제 도로점을 출발점으로 한 복원

이번에는 목표그림/사물명/그림배치 입력 없이 실제 도로의 자연고리를 추출했다. 기존3지역 파일은 bbox/hash만 사용, 기존 그림별 경로와 배치는 읽어 사용하지 않았다. buildBlocks/growLoops seed83721, StepBudget2000으로 수집한 대전1948/대구3509/송파4102고리에서 실제간선·영역·폐곡선·거리3–8km·반복20% 조건을 확인하고 동일간선 고리 중복제거 후 반환순 첫6개씩18개를 고정했다. 좋은 모양을 보고 선별하지 않았으며 첫6개는 비슷한 이웃고리에 편중될 수 있다.

실제 도로고리→하나의 관측획→32점 근사→코너/끝점 보존 sparse점→보간→기존 무라벨 다중획 잔차모델(seed17) 순으로 실행했다. 사물 정답이나 참고그림 없음, 재학습 없음. 입력 획구분/순서는 추출한 고리의 연결순서에서 온다. 전체 도로망의 임의 점 중 사물부분을 선택하는 학습모델은 아직 아니다. 이 파일럿은 내부획이 없는 고리 한획이며 기존 다중획 학습 분포와 차이가 있다.

모델출력은 실제도로가 아닌 추론 곡선이다. 보간대비 모델변화량 평균42.78m는 정확도/향상치가 아니다. 추론곡선으로 새 주행경로를 만들거나 도로 유효성을 주장하지 않는다. 원본도로는 검사 통과했으나 곡선은 도로 밖을 지나갈 수 있다.

대전 첫4개 몽타주 시각 검토에서 보간 및 모델이 큰 모양을 유지하며 요철을 보정하는 모습이 보였다. 사물 정체성을 복원하거나 새 사물후보를 발견했다는 증거는 없다. 이 모델은 잔차 복원기이지 분류기/새획 생성기/의미선택기가 아니다. 사물 이름을 억지로 붙이지 않고 null로 남겼다. 도로입력 적용 자체는 완료했으며 최종 목표 달성을 주장하지 않는다.

실험테스트1개 및 전체 타입검사 통과. 추론 입력/출력끝점 보존 assertion 통과. 기존 Vite __dirname 경고 있음. checkpoint/입력파일SHA256 기록. 원본12조건/앱 기본 변경 없음.
