# v12: 25종 범주를 포함한 학습 선택기

v11은 25종×3개 개발 지역75요청 모두에서 유효 도로를 얻었지만, 생성기 첫 후보의3AI 명확 다수결은8/75였다. 학습 v10은 동물 범주가 없었다. 이번 가설은 동물과 누락 사물 범주를 손그림으로 학습하면 동일 도로 후보에서 대상에 맞는 선택이 개선된다는 것이다. 범주 추가만으로 특징 생성 실패를 해결한다고 가정하지 않는다.

## 수집·학습 고정

v10의19범주72개씩은 원본 캐시와 분할을 보존해 재사용한다. 동물11범주 cat,fish,dog,rabbit,bird,whale,sea_turtle,elephant,giraffe,butterfly,duck 및 사물 rocket,apple,crown을 추가한다. 거북이 학습 자료는 공식 sea turtle 범주이며 일반 거북이에 대한 동등한 성능을 뜻하지 않는다. 총25추천범주+8일반경쟁범주=33범주, 각72개, 총2376개를 계획한다. 부족한 범주는 실패 기록하며 조용히 제외하거나 대체하지 않는다.

공식 Quick Draw simplified 자료의 recognized=true 첫72개 고유 유효 예시, 최대10000행/8MB 검색, 원래 point-contour 자료 ID 제외, 전체 획 사용, 회전·획순서·역방향 동일기하 중복 제외, 기존 split-v10 그룹 해시70/15/15를 보존한다. 기존 v10과 겹치는 예시는 의도적 재사용이며 새 독립 test라고 하지 않는다. 도로 판정/경로는 학습·검증·임계값 조정에 쓰지 않는다. 원본 클래스별 최소 split3개 기준을 유지한다.

동일 로컬CLIP·4회전·렌더러로 특징을 추출한다. 코드 해시가 달라졌으므로 기존 특징의 무검증 혼합 없이 새 데이터2376개와 v11 도로1003개를 다시 추출한다. 결정적 균형ridge와 train-only prototype, lambda/검증 margin 후보·선택 규칙은 v10과 같다. test macro accuracy가 prototype보다5%p 이상 높고 일반 경쟁 오수락이 증가하지 않는지를 보조 기준으로 기록한다. 인간 인식 확률이 아니다.

## 도로 대조 고정

v11의1003개 원본 도로 후보와75요청을 보존한다. 기존 첫 후보가 baseline(8/75)이다. 새 추천은 각 요청의 같은 area/proposalShape 후보 중 v12 head가 의도를 맞게 예측하고 검증 margin을 통과한 후보의 margin 최대값1개다. 동률 source id 사전순. 매핑은 cat/fish/dog/rabbit/bird/whale/elephant/giraffe/butterfly/duck 직접, turtle=sea_turtle, mug=coffee_cup,tshirt=t-shirt,bottle=wine_bottle, 나머지 직접이다. 추천이 없으면 보류로75분모에 남긴다. 후보 좌표·연결·길이·반복·영역을 바꾸지 않는다. 같은 기하의 중복은 기록하며 독립 표본이라 주장하지 않는다.

prototype에도 동일 요청별 선택 규칙을 적용한다. 전역 의도무관 선택은 진단 전용이며 이번 성과 기준에 쓰지 않는다. 범주별 실패를 전체75개와 함께 보고한다. v11의3지역은 이미 본 개발 지역이며 holdout이 아니다.

가시적 개발 기준: head 대상일치 clear 다수결이 baseline8/75보다 최소5개 증가(>=13/75), 동물 최소3종·사물 최소3종이 각각2지역 이상 clear, 유효 도로100%, 보류분모 보존. 모두 만족해야 통과다. 평가자별 원본 판정도 유지한다. 이름/방법/점수/참고 외곽이 없는 중립 경로와 무작위 토큰으로3AI 자유 명명한다. 기존 동일 픽셀에는 기존 판정을 연결하고 새 성공으로 중복 집계하지 않는다. 실제 사람 평가는 별도이며 AI로 대체하지 않는다.

실패하면 분모·범주·동의어를 사후 변경하지 않고 모델 분류와 도로 특징 부족을 구분한다. 원래 고정12조건, 원래 점수식, holdout-v2, 앱 기본을 변경하지 않는다. 학습 개선·도로 개선·사람 인식을 각각 구분해 보고한다.

자료 출처: https://github.com/googlecreativelab/quickdraw-dataset (CC BY4.0; recognized는 게임 모델 판정).

## 수집 실패 기록 — 특징 추출·학습 전

공식 categories.txt를 확인했고 rocket 범주가 없으며 해당 URL은404를 반환했다. 원래25범주 전부를 학습한다는 수집 조건은 실패했다. 범주 대체는 하지 않는다. 실행 가능한 학습 자료는24추천+8일반=32범주2304개로 명시하고, 로켓3요청은 학습 선택기 미지원 보류로 원래75분모에 남긴다. 따라서 전체25종 학습 지원을 달성했다고 주장할 수 없다. apple/crown 수집을 계속하고 나머지 모델 비교는 원래 성공 기준으로 시행한다. 이 수정은 특징 추출·학습·v12도로 판정 전이며 test를 보고 범주를 선택한 것이 아니다.
