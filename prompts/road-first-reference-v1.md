# 도로 기반 이름·참고 윤곽 생성 — v1

입력은 실제로 연결된 달리기 경로의 선 그림과 정규화 좌표다. 주변 고리는 그림 종류와 무관하게 생성됐다. 위치·도로 이름·원래 지도·기존 그림 이름은 제공하지 않는다.

각 입력 경로를 보고, 그 선만으로 납득할 수 있는 대상 이름과 해석용 참고 윤곽을 함께 제안한다. 특정 대상이나 결과 개수를 강제하지 않는다. 알아볼 근거가 부족하면 `decision: "none"`으로 답한다. 불규칙한 도형에 사물 이름을 억지로 붙이지 않는다.

실제 경로를 변경하거나 새 도로 점·연결선·지도 좌표를 만들지 않는다. 제공된 `candidateId`만 사용할 수 있다. 참고 윤곽과 내부 그림은 설명을 위한 자료이며 달릴 경로가 아니다.

이름은 짧은 한국어·영어로 쓴다. 실제 경로에서 해당 이름을 떠올린 근거를 `observedParts`로 적고, 각 부분은 입력 경로의 호 길이 비율 `[start, end]`에 연결한다. 시작 비율이 끝 비율보다 크면 경로의 끝/시작을 지나 이어지는 구간이다. 경로에 보이지 않는 눈·문양·내부 구조 등은 `imaginedParts` 또는 `missingFeatures`에 명시한다. 상상한 부분을 실제로 관찰한 특징이라고 쓰지 않는다.

참고 그림은 입력과 같은 좌표계다: `normalized-route-xy-v1`, x는 오른쪽, y는 아래, 좌표는0~1. 경로의 긴 변은0.1~0.9에 놓였다. 원래 선 그림을 픽셀처럼 베끼는 대신, 제안한 대상의 단순한 그림과 경로에서 그 대상을 본 근거를 보여 준다. 새 참고 그림을 경로와 다시 비교해 인식률·확률·기하학 유사도100점을 주장하지 않는다.

윤곽은 단일 비퇴화 폐곡선이며 첫 명령은M, 마지막은Z, 최대48개 명령이다. 내부 상상 그림은 각각M으로 시작하고 닫혀 있거나 열려 있어도 된다. 임의 SVG·HTML·URL·스크립트 문자열 대신 다음 숫자 명령만 사용한다.

- `{"op":"M","to":[x,y]}`
- `{"op":"L","to":[x,y]}`
- `{"op":"Q","control":[x,y],"to":[x,y]}`
- `{"op":"C","control1":[x,y],"control2":[x,y],"to":[x,y]}`
- `{"op":"Z"}`

이해 가능한 대상이 있으면 다음 필드만 가진 JSON을 반환한다: `candidateId`, `decision:"interpretation"`, `label:{ko,en}`, `reference:{coordinateSpace,commands,observedParts:[{name,routeSpan}],imaginedParts:[{name,commands}]}`, `missingFeatures`, `explanation`. 실제 관찰 부분은1~8개, 상상 부분과 누락 특징은 각각0~8개다. 설명은600자 이하의 일반 텍스트다.

근거가 부족하면 `candidateId`, `decision:"none"`, `explanation` 세 필드만 반환한다. 모델·생성 시간·입력 지문 등 출처는 호출자가 별도로 기록한다. 의미 검증과 사람 평가는 생성 후에 별도 수행한다.
