## 구현

실제 OSM 그래프 → 사물 외곽별 도로 후보 생성 → 정밀 검증 → 생성 각도로 정렬 → CLIP 전체 이름 경쟁 → 사물 가설 일치·거절 → 선택·익명 검토·원본 GPX 출력.

- `src/lib/route/objectProposals.ts`: 재사용 가능한 생성·정확한 노드 복원·검증. 예산 소진과 부분 실패를 기록하고 같은 도로의 다른 사물 가설을 보존한다.
- `src/lib/route/objectTemplates.ts`: 의류·도구6종의 명시적 외곽 사전. **학습 가중치가 아니다.** 기존 SHAPES는 수정하지 않았다.
- `scripts/recognition-lab/road-object-model.py`: 추론·일치 선택·익명 화면·GPX를 한 명령으로 실행한다.
- `road-clip-ranker.py`, `road-semantic-gate.py`: 설치된 공식 동결 CLIP의345개 이름을 모두 경쟁시킨 뒤 생성 가설과 일치한 후보를 선택한다. 제외 클래스가 이기면 거절한다.
- `road-ranker-review.py`, `road-ranker-score.py`: 평가자별 자유 명명·답변 저장·실패와 보류 포함 집계·평가자 일치도를 지원한다.

기존6종과 새6종 외곽을 탐색한다. rocket은 현재 사전에 없어 일치 검증에서 보류된다. 모든 사물을 생성하는 범용 모델은 아니다. 최종 점수 `cosine * generatorSimilarity / 100`은 선택 휴리스틱이며 사람 인식 확률이 아니다.

모델은 도로 좌표를 수정하지 않는다. 회전은 입력 이미지와 표시 방향에만 적용한다. GPX에는 원래 위경도·노드 경로를 보존한다. 원래 고정12조건·평가식·holdout-v2와 앱 기본은 변경하지 않았다.

| 3 | 기존6사물 외곽으로105개 추가, 총465개 | 0/6 → 0/6 | 생성 예산 증가만으로 부족 |
| 4 | 생성 배치각 역회전 정렬 | 0/6 → 0/6 | 집 연상은 생겼으나 기준 미달 |
| 5 | 생성 가설과 모델 최고 이름 일치 | 0/6 → 0/6 | 약한 연상5/6·보류1/6 |
| 6 | 같은v5를 수원·청주·광주에서 검증 | 0/6 → 0/6 | 약한 연상2/6·보류2/6 |
| 7 | 의류·도구6종 추가, 총551개 | 0/6 → 0/6 | 원래 단일 평가 기준 미달 유지 |
| 8 | 고정v7을 천안·전주·울산550개로 검증 | 0/6 → 0/6 | 새 지역 보조 다수결1/6 |

1회차는 새 신경망을 실제로 학습했지만 실패했다. seed17 합성 음성 오수락은 상대60% 줄었으나 seed29는 악화했고 원본 정확도도5.6%p 하락했다. 유리한seed만 골라 성공으로 바꾸지 않았다. 합성 음성은 실제 도로의 ‘사물 없음’ 정답이 아니다.

이후의 예시는 새 CNN 가중치의 우위가 아니라 **실제 도로 생성·동결 CLIP·선택 정책을 연결한 시제품의 결과**다. 생성 예산이 늘어난 효과를 순수 모델의 동일예산 우위로 해석하지 않는다. 실행 전 계획·실패·익명 판정·고정 분모는 `protocol*.md`, `ai-review*.json`, `evaluation*.json`에 보존했다.

## 평가자 차이와 작은 성과의 범위

v7 최초 판정 수신 전에 추가AI2명의 일치도 검토 계획을 기록했다. 원래 평가자의 실패를 덮어쓰지 않고 별도 보조 지표로 보고한다.

| 자료 | 원래 평가자 | 추가 평가자2 | 추가 평가자3 | 3명 중2명 이상 clear | baseline 다수결 |
|---|---:|---:|---:|---:|---:|
| 개발v7 | 0/6 | 2/6 | 5/6 | 2/6 | 0/6 |
| 새 지역v8 | 0/6 | 1/6 | 2/6 | 1/6 | 0/6 |

v7의clear2개는 같은 대전 지역이고 간선Jaccard가0.8778626이다. 따라서 가까운 **한 형태 계열**이며 독립적인 두 지역 성공이 아니다. 지역 요청 기준 보조 성공은1/3, 추천 슬롯 기준은2/6이다. v8에서는 다른 지역 울산의 망치 경로를 얻었지만 전체 보조 기준+2/6에는 미달했다. 보류2개도 분모에 포함했다.

세AI는 문맥이 분리돼 있으나 같은 계열일 수 있어 오류가 상관될 수 있다. 원래 평가자는 끝까지 명확 인식0/6으로 보았다. 실제 사람 인식률은 미측정이며 사람3명 이상의 독립적인 이름 없는 자유 명명이 필요하다.

v9의550개 모델 관련 입력과 v8이 같았고 익명 SVG·몽타주도 정확히 같았다. 이미지SHA256은 `870557fa1f4c850547a64ebcec106ea88c0731648c3a7a634b9e764c53158c12`다. 같은 그림을 다시 판정받아 점수를 올리지 않고 fingerprint bridge로 기존 판정을 재사용했다. **v9를 새 성공이나 독립 검증으로 중복 집계하지 않는다.**

## 검증과 한계

모든 포함 경로에 실제 간선·정확한 노드/좌표 대응·폐곡선·영역·native/projected 거리3~8km·반복20% 이하를 검사했다. 최종550개에서 입력 해시와 모든 원본 필드 보존도 별도로 확인했다. 지도 데이터는2026-10-09 기준이며 현장의 최신 통행 상태를 보증하지 않는다.

- 일반 테스트319개 통과, opt-in 등112개 skip.
- 신규 Python14개, 타입 검사, 새TypeScript 파일lint 통과.
- UI는 이전 답변 자동 노출 방지·평가자 코드 분리·파일 다운로드를 확인했다. 임시 저장이 차단된 브라우저에서도 다운로드가 동작한다.
- Windows 기본 임시 폴더에서는 worker 임시파일ENOENT가 발생했다. TMP/TEMP를workspace 안으로 지정한 실행에서 통과했다.

일반 검사 통과는 인식 성과의 증거가 아니다. 무거운 생성 실험은opt-in으로 별도 실행했다. v8은 생성227.8초+모델/결과 출력206.7초, 합계 약7.2분이었다. v9의88.8초는 자연360개 추론을 재사용한 추가 실행시간이며cold 전체시간이 아니다. 10초 실시간 추천은 미달이며 앱 기본 모델 교체와 제품 출시는 보류했다.

## 사람 검토와 재현

사람 검토 화면은 처음에는 빈 답변만 보인다. 본명 대신 서로 다른 평가자 코드를 사용하고 다른 사람의 답변을 보지 않는다. 답변은 다운로드한JSON으로 모은다. `diagnostic.html`의 이름·점수는 자유 명명 뒤에 확인한다. AIv7과 사람 검토 그림의 픽셀은 같지만 UI/저장 방식 변경으로 fingerprint는 별도다.

로컬 한국 도로SQLite·고정 스냅샷·준비된Python 환경·공식 로컬CLIP 캐시가 필요하다. 새 모델 다운로드나 유료 외부 호출은 하지 않았다. 상세 좌표/가중치/환경은Git 제외 영역이므로 코드와 보고서만으로 모든 실험을 재현할 수는 없다. 버전은 `runtime.json`, 실행 소스는 `code-snapshots/`와 해시 기록을 확인한다.

검증된 후보 파일에 모델 실행:

```powershell
eval/recognition/model-env/Scripts/python.exe scripts/recognition-lab/road-object-model.py --input eval/recognition/road-ranker-20261102/proposals-v7.json --out eval/recognition/road-ranker-20261102/my-run --public-out public/eval/my-road-review --extended-templates
```

새 출력 폴더를 사용해야 한다. 이미 동결한 결과는 덮어쓸 수 없게 보호했다. API·평가·재현 방법은 `docs/road-object-model.md`에 정리했다.
