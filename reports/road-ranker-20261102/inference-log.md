# 추론 입력 동결 기록

v3 생성기는 요청별 진행 결과를 incremental 저장한다. 첫 CLIP v3 추론은 생성 종료 직전 458개 스냅샷을 읽었다. 최종 생성 결과는 465개(원래360+신규105),18요청 완료,오류0이다. `predictions-clip-v3.json`은 이 중간458개에 대한 계산 캐시로만 보존하며 최종 평가에 쓰지 않는다.

최종465개 파일을 입력으로 `predictions-clip-v3-final.json`을 새로 생성했다. 동일 후보/모델revision/사전/정책/좌표가 정확히 같은 경우에만458개 추론값을 재사용하고 나머지7개를 추론한다. 모델 가중치와 선택 정책은 바꾸지 않는다. 생성 중인 파일을 추론기가 읽지 못하도록 status=complete 검사도 추가했다. 익명 평가 세트는 최종465개 추론 완료 후에만 만든다.
