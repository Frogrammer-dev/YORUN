# 곡선 출력 축소 실험 결과

공식 Cloud2Curve 재현/실행이 아니다. 논문의 점→파라미터 곡선 표현에서 착안한 고정 cubic4개 폐곡선 모델을 구현·학습했다. 공식 가변 차수, Set Transformer, 다중 획 순차 생성, 획별 분할/분포 학습을 포함하지 않는다. 따라서 이 결과로 Cloud2Curve 자체의 가능성을 기각할 수 없다.

기존 Quick Draw590개/3클래스, train413/val88/test89. 학습60epoch, 최적 검증epoch56. 저장된 기존 모델과 완전히 동일한267테스트입력으로 비교했다. 두 학습 모델 모두 정답 클래스를 입력받으므로 사물 분류/발견 능력 검증이 아니다. 기존 좌표모델은 저장 체크포인트를 사용했으며 출력 파라미터 수/학습 배치 순서까지 일치시킨 쌍 실험이 아니다.

| 방법 | 전체 Chamfer 거리↓ |
|---|---:|
| 고정4곡선 모델 | 0.039223 |
| 기존64좌표 모델 | 0.036725 |
| 각도순 단순 보간 | 0.034968 |

곡선 모델은 기존 대비 약6.8%, 보간 대비 약12.2% 오차 증가. apple/fish/bird 모두 기존 모델보다 악화. uniform8에서는 보간보다 나으나 기존 학습 모델에는 못 미친다. 부분조건만 선택해 성공으로 보고하지 않는다. 원본89개 단위 bootstrap으로 곡선−좌표 차이95%구간[0.001639,0.003408]. 한 학습 seed의 데이터 재표집이며 학습 초기값 불확실성을 포함하지 않는다. 사전10%개선/클래스비악화 기준 미달.

고정4구간/12제어점은 복잡한 꼭짓점을 표현하기에 제한될 수 있으며, 곡선의 균등 파라미터 샘플과 정답의 균등 호길이 샘플에 좌표MSE를 적용한 대응 오차도 있을 수 있다. 이는 가능한 원인이지 검증된 설명이 아니다. 다음 단계는 획/특징점에서 나눈 여러 곡선과 가변 복잡도, 호길이 대응 또는 순서 불변 손실을 분리 검증하는 것이다. 변경 전 단순 비학습 곡선 피팅 대조도 필요하다. 이번 단순 보간은 베지어 피팅 대조가 아니다.

검증: 캐시SHA256/모든 정답윤곽 해시 일치, 입력점 순열 불변, 곡선 구간 시작점 일치, 기존 모델267출력이 이전 저장 출력과 일치 확인. 베지어 끝점은 다음 구간 시작점을 공유하는 구조로 폐곡선 연결. 내부선/사진/실제도로/사람인식은 미측정. 앱 기본 변경 없음.

재현: model-env Python으로 `scripts/recognition-lab/curve-pilot.py`. 저장 모델/상세출력은 gitignored `eval/recognition/curve-pilot-20261029/`. 화면 `public/eval/curve-pilot-20261029.html`은 클래스별 테스트 첫4개 uniform8의 입력/정답/세방법 비교. 사례는 성능으로 고르지 않았다.
