# 5회차: 생성 가설과 시각 모델의 일치

v3/v4 개발 진단에서 raw CLIP cosine이 높은 불규칙 경계가 생성된 사물 외곽보다 먼저 선택되는 현상이 남았다. v5는 사람이 미리 고른 개별 경로를 쓰지 않고, 모든 생성 가설에 같은 검증 규칙을 적용한다.

가설: 생성된 외곽의 사물 가설과 CLIP345개 전체 경쟁의 최고 사물 이름이 일치한 경우만 채택하면 불규칙 경계 오수락을 줄일 수 있다. 허용 매핑은 house=house, tree=tree, car=car, airplane=airplane, mug=coffee_cup 또는 cup, rocket=rocket이다. 원본 vocabulary의 실제 키를 사용한다. rocket은 현재 사전에 없으므로 대체 이름을 억지로 넣지 않고 해당 생성 가설을 보류한다. 모든 제외 클래스도 경쟁한다.

동일465개와 v4의 모든 회전별 추론을 그대로 사용한다. 각 회전에서 기존 cosine>=0.30/margin>=0.003/전체top1 허용class 규칙을 통과하고 생성 가설과 일치하는 view만 남긴다. 그런 view 중 cosine 최고를 선택한다. 자연360개는 생성 가설이 없으므로 이 정책에서 보류되지만 최종 요청 분모6은 유지한다. 따라서 발견형 전체 범주 해결이 아닌 여섯 외곽 가설 기반 추천이다.

최종 순위 점수는 CLIP cosine*(원래 generatorSimilarity/100)으로 고정한다. 모델 간 확률 합산이 아닌 검증되지 않은 복합 선택 휴리스틱이다. 이 수치는 사람 인식확률이 아니다. 지역별상위2, 부족한슬롯은보류실패, 기존baseline2/지역을 보존한다. 같은각도 동일후보는 중복 평가하지 않는다. 명확한 자유명명 AI 대리 +2/6 이상과 실제도로유효성100% 기준을 유지한다. 이름/점수/목표그림/방법을 숨긴 별도평가를 수행한다. 실제사람평가는 여전히 남는다.

이 회차는 같은 개발 후보에서 선택 정책을 수정한 실험이다. 신규 독립 검증이나 새 학습 모델로 포장하지 않는다. 결과를 보고 임계값/동의어/분모를 바꾸지 않는다.
